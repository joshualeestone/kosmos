# Security

## Reporting a security problem

If you find a security problem in Kosmos, please email **security@installkosmos.com**.

Please include:

- what you found and what it lets someone see or do;
- the Kosmos version you saw it on (Kosmos shows it in Settings);
- the steps to reproduce it.

Please do not open a public GitHub issue for a security problem. This repository is public, so
an issue would show the problem to everyone before it is fixed.

We acknowledge reports, fix what we confirm, and tell the people affected.

## What this covers

This repository is the Kosmos app: the board, the engine that runs agents, and the command
line tools that ship with it. The Kosmos+ service (the coordinator, the relay and the tunnel)
lives in the kosmos-relay repository. If you are not sure which one a problem belongs to,
email us anyway.

## Supported versions

Only the latest release is supported. Fixes ship in new releases.
