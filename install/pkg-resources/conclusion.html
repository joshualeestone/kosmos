Kosmos is ready

Kosmos is installed and running, and your dashboard should have opened in your browser.

If it did not, open Kosmos from your Applications folder. Kosmos starts on its own each time you log in, so you will not have to do this again.

The first time you connect an agent, Kosmos downloads the tools it needs. That can be a few hundred megabytes and take a few minutes on a new machine, and Kosmos asks before it starts.
