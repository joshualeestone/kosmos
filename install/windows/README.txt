Kosmos for Windows (unsigned preview)

TO INSTALL
  Double-click "Install Kosmos.cmd".

WINDOWS WILL WARN YOU, AND THAT IS EXPECTED
  You will see a blue box saying "Windows protected your PC", and the only
  button showing is "Don't run".

  Click "More info" first. A "Run anyway" button then appears.

  This happens because this build is not signed yet. It is not a sign that
  anything is wrong with the download. A signing certificate is being bought
  separately; once it is in place this warning goes away.

WHAT YOU GET
  Kosmos opens in your browser and your projects work.

  The agents panel will say it cannot see anything running. That is correct
  on a fresh machine rather than a fault: no agents have been started here.
  Running agents on Windows is later work and is tracked separately.

TO UNINSTALL
  Run "Uninstall Kosmos.cmd" from the installed folder, or delete
  %LOCALAPPDATA%\Kosmos and the two shortcuts it made.
