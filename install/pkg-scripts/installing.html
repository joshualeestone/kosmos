Installing Kosmos

Setting up. Usually a minute or two.

Most of the wait is one large download, then Kosmos unpacks and moves into your Applications folder.

This page shows install progress. Kosmos opens in its own app when it is ready.

Still going. A slow one can take a few minutes; the installer window will say if something went wrong.

If Kosmos has not opened yet, it may not have finished installing, or it may have been set up for a different account on this computer. You can open Kosmos from your Applications folder, or install your own copy from installkosmos.com.

Something is already running on this computer at the address Kosmos uses, so this page will not jump to it on its own. On a Mac with more than one person's account, this is often THEIRS, not yours.

If it is not yours, close it without changing anything. Your own copy of Kosmos is in Applications.
