# #5957 slice 3: an agent that has not run for two weeks says so, and points at Remove

**Branch:** `idle-5957` (stacked on `rulesbehind-5957`, slice 2) · **Card:** kosmos#5957 (slice 3 of 3).

## The defect
Josh's Windows QA (10-12): a stale "Gemini" had not run since 09-26 and was still a project member, and nothing on the
board said so. The card asks to "offer to archive or remove agents that have not run in 2 weeks".

## The call (on the card, comment 6130868785)
Kosmos has no archived-agent state (only projects archive), so this slice does not invent one. A stopped agent that has
not run for 14 days or more says so on its offline card and list row, and points at the Remove that already exists on
its page. Kosmos removes nothing on its own. Rejected: a new "archive agent" state (open questions about rooms,
schedules and the name; a much larger surface for a list Remove already prunes).

## Where "last ran" comes from
`engine/liveness.js`: every authenticated report beats it (server.js, the report route), Mac and Windows alike.
Measured on this Mac 10-12: the liveness directory holds a file per agent, one last written 08-29. `idleDays(name, now)`
is a whole number of days only at `IDLE_DAYS` (14) or more; null under that, and null with no record or an unreadable
one (never seen is not "seen long ago", the module's three-answers rule).

## Where it is said
Only the OFFLINE row (server.js), the not-running card (`.arules`) and list row (`.ltask`), through one helper
`offlineNote(a)`: the slice 2 rules sentence first, then "Has not run in N days. If it is no longer needed, Remove is
on its page." Not on the could-not-check split (jobRunningUnseen). A running agent is running, so it is not said there.

## Weakest premise
The last report time stands in for "last ran". An agent that runs without ever reporting (a hook broken) would read as
idle while working. It is said only for a STOPPED agent, which bounds that: a stopped agent is not running now.

## Not in this slice
A Settings list of every agent's rules version, last run and summary freshness (the card's last sentence).
