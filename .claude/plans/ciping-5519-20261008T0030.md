  existing endpoint override) as a plain http(s) URL, the unit carries it, so a systemd-started board keeps it across
  restarts; an update re-runs setup from the board's own environment, so it persists. Unset (every real install): the
  unit is byte-identical (test). Unsafe values (whitespace, quotes, backslash, %, non-http) are left out, not fatal.
- The workflow sets it job-wide to http://127.0.0.1:9/api/created, asserts the unit AND the running board's
  /proc/<pid>/environ carry it, adds it to the 0.7.27 unit it restarts in the update step (that release's unit writer
  cannot), and asserts the updated unit keeps it.
- Stacked on linux-setup-board-4920 (#5485), which makes setup.sh write the unit through linuxboard.js.
