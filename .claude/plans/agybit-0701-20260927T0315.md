check: "the executable bit differs from the tree: app/bin/agy-report-bridge.js". #4043 (e943a4d93)

## Decision

Set the tree's mode to 100755, matching the three sibling bridges, the builder's intent, and the file's
own `#!/usr/bin/env node` shebang. No content change.

**Rejected:** dropping the builder's `chmod +x` (every sibling bridge is executable; the supervisor
treats them alike), and a stale override (the check exists so a shipped file equals the tested one).

(bin/agent-supervisor.sh:786); either way the tree now matches what ships, which is what 4b checks.
