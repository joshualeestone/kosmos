# DM-notification tally tile (#2863, agents tally)

## Ask
Josh, 2026-09-11: "we should tally those at the top for both agents and also for projects so you can
see where notifications are happening and need you."

## Context
The engine field a.dmUnread shipped in Angel's #2881; the per-agent grid-card badge shipped in #2885.
This is the AGENTS half of the top tally: a "Messages" tile in the agents tile row that rolls up the
per-agent DM bubbles. The projects half (a projects-board tally = sum of p.unread) is the follow-up.

## What finished looks like
The agents tile row (Agents / Working / Idle / Needs you / No project) gains a "Messages" tile showing
the total unread direct messages across the fleet, hidden at zero like the attention tiles, so a quiet
board is unchanged.

## Approach (web/index.html only, mirrors the tile-row grammar)
- Markup: a `.stat` tile (`#st-dm-tile` / `#st-dm`, slab "Messages"), after the needs-you tiles, with
  its own muted message-bubble glyph (`.dmtile-g`, `--k-ink-2`) rather than the red `.haz` alert mark:
  unread DMs point you somewhere, they are not a fault. Not part of the Working+Idle=Agents arithmetic,
  so it sits after the state tiles as its own signal.
- JS: sum client-side from `data.agents` (a.dmUnread), exactly as Working/Idle are counted from the
  fleet rather than trusting a second server derivation. A null dmUnread (unknown, mirroring p.unread
  null) contributes 0, never a guess; negatives clamp to 0. Set `#st-dm` + hide at zero. On a failed
  poll, `?` + hidden, the same choice the red tiles make (a stale count would claim something the poll
  cannot stand behind).

## Decisions / weakest premises
- The tile shows the SUM of unread messages (the rollup of the per-agent bubble numbers), matching
  "tally those notification counts". WEAKEST PREMISE: Josh may prefer a COUNT of agents who messaged
  you (like "Needs you" counts agents) rather than total messages; that is a one-line change to the
  reduce.
- Muted glyph, not a red alert tile, so it does not compete with the red "Needs you". If Josh wants it
  louder (red), that is a class swap.

## Deferred (the projects half)
- The projects tally (sum of p.unread) on the Projects board, its own increment.
