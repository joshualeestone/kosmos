# linuxrunners-5419: Linux port, #5419 slice 2: provider runners (Codex, Gemini, Grok) download on Linux

Stacked on slice 1 (linuxclaude-5419, PR #5453). Once slice 1 merges, this branch's own commits are cherry-picked onto
main and the PR opened against main.

## Goal
On a Linux board, Settings can install OpenAI's Codex, Google's Gemini CLI and xAI's Grok CLI, each verified against
the vendor's published integrity before it is placed, exactly as on the Mac and Windows.

## Change
- `engine/platform.js`: `CODEX_DOWNLOADS` and `KEYED_RUNNER_DOWNLOADS` include `linux`. `RUNNER_DOWNLOADS` (the
  claude arm of runners.install) is unchanged: Claude installs through connect.download (slice 1).
- `engine/runners.js`: `CODEX_LINUX` and `GROK_LINUX`, keyed by CPU, and `manifestFor` branches that lay them over
  the base entry. A CPU with no build (ia32) gets the x64 entry and the arch guard refuses it by name. Gemini's
  bundle is one tarball everywhere and keeps the POSIX launcher. The install path, stable symlink and node launcher
  are the Mac's POSIX path, unchanged.

## Measurements (2026-10-06 22:55 CDT, each tarball streamed; sha512 matched the registry; size and paths read)
- codex 0.149.1 linux-x64: 125550959 bytes, binary vendor/x86_64-unknown-linux-musl/bin/codex
- codex 0.149.1 linux-arm64: 118078094 bytes, binary vendor/aarch64-unknown-linux-musl/bin/codex
- Both are static musl, so one build per CPU serves glibc and Alpine.
- grok 1.0.41 linux-x64: 49179836 bytes; linux-arm64: 44233139 bytes; layout bin/grok.br (expanded to
  bin/grok-native), as the Mac.

## Weakest premise
Grok's Linux binary is assumed to run on glibc distributions (its libc is not measured), and nothing here runs any
of the three on a real Linux machine. The Linux lane (#4919) runs the suite there; running a real turn is piece D's
end-to-end check.

## Tests
`engine/runners.linux-5419.test.js` (literal pins per CPU, Gemini parity, ia32 refused by name before a byte moves,
the gates), and the existing gate tests now use freebsd as the unsupported platform and assert linux is allowed.
