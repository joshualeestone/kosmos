## Measured before building
On main 7ef94612f, with Claude Code 2.1.296, I started Claude Code in a scratch folder whose CLAUDE.md imports one
file outside it, captured the question screen, and ran `classify` on it with the pane fixture the status tests use.
It already read `needs_you`, with the generic reason "it is waiting for you to answer a prompt". The family
detector for confirm dialogs (#1919) catches it. So option 2 of the card was mostly true already; what was missing
is the reason saying which question it is.

## Change
One entry in `CONSENT_PROMPT_HEADINGS` in `engine/status.js`, and two tests in `engine/status.test.js` built on the
captured screen (one row changed: the imported file's path).

## Decisions
- **The heading is matched as a whole row.** The bypass heading beside it is matched anywhere in a row. A whole-row
  match means prose that quotes the question above another dialog does not label that dialog.
- **No claim about the default answer.** The detector does not read the highlight, and an existing test forbids
  claiming it.
- **Nothing presses the answer.** It is the person's.
- **Not changed:** answer buttons on the agent's page. `chat.optionsIn` returns nothing for this screen; that is
  separate work and not measured further here.
- **Weakest part:** the heading text comes from one Claude Code version. If a later version rewords it, the card
  falls back to the generic reason, which is what it shows today.
- **What would change my mind:** a card that shows this reason for a screen that is not this question.
