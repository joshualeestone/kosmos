  agent chose one. The private runtime home stays as is (it never copies account config; the overrides are argv).

  "Alibaba Qwen" entries, an endpoint form (URL, model, key) in Add a provider.

on a fixed task set, with qwen2.5:7b as the floor and Qwen Code as the comparison arm. If Codex cannot drive it,
