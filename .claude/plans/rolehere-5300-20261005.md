# rolehere-5300: a member says what it does on one project

Card: #5300 (10-05 user diagnostic R10; N11 in the 0.7.15 one). On a project every member showed "Project Manager".
#4896 fixed a different cause. Read from source: a member's role is its agent's own role (profile, else card), and the
New Agent screen's Single path opens in Project Manager mode, so five quick creates are five Project Managers and the
list is truthful. The report's ask: "let the role say what the agent does on that project".

## Decided
Build a per-project role an agent sets for itself. Rejected: changing the Single path's default (it is Josh's #4556
design, and it would not fix agents already made); a screen control (later; the route already takes `name` from the
screen).

## Change
- engine/projects.js: `rolesHere` on the project (session name -> words); setRoleHere(id, name, role) (member only,
  one line, control and bidi characters to spaces, at most ROLE_HERE_MAX = 60, empty clears); removeAgent drops it;
  describe carries it as `roleHere` (text or null), display only; `role` is unchanged. The projects block teaches
  the verb.
- server.js: POST /api/project/:id/role {role}; an agent sets only its own (token, else pane, as task built does; a
  name in the body is not read); the screen names the member. In AGENT_TOKEN_ROUTE_PATTERNS (pin updated, with why).
- install/kosmos and tools/windows/kosmos-cli.js: `kosmos project role <project-id> "<what you do here>"`.
- engine/projectview.js: project show prints the member's own role, then `on this project: "<words>"` (quoted:
  agent-written words, so they cannot pass for Kosmos's own).

## Tests

other project untouched, leaves with membership, one line); cli.project-role-5300 and its Windows twin. Perturbed:

  person saved (#4896). Now `role` is untouched and `roleHere` is shown beside the member in project show only.
  The web member list is unchanged (it shows `role`).

## Weakest premise
Two: that agents will set it (the block teaches the verb, nothing makes them), and that the screen half follows; until
it does, the person still sees each agent's own role on the page. The block teaches the verb, but an agent never asked to set a role keeps showing its own;
the five Project Managers in the report would still read so until each says what it does.
