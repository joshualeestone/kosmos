## The two-arm local verifier (the key method)
Run each fixed file under a BOARDLESS + HOMELESS proxy:
  AGENT_WORKFORCE_TMUX_BIN=/nonexistent/tmux  (board arm: makes a live paneRoster/capturePane THROW)
  node --require <fs-probe.js>                 (fs arm: os.homedir() -> a fresh tempdir)
fs-probe.js lives at the scratchpad: it monkeypatches os.homedir so ANY ungated real-home
read/write goes to disposable space. **Splinter's correction was load-bearing:** the tmux arm
alone is blind to filesystem deps; the fs arm caught the claude-binary dep in register-1531 AND
the real-fleet-store read in web.task-page. A test is hermetic only when it passes BOTH arms
AND normally.

The existing seams (all in status.js / env):

- AGENT_WORKFORCE_HOME - the home seam; create.js homeDir() + store.js root() honor it AFTER
  Mona Lisa's #1780 (lands tonight). 6 modules already honor it.
