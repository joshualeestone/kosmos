# kosmos#1794: make the 24 non-hermetic engine tests CI-safe

## Goal
kosmos CI (the held ci-workflow-835 / PR #1792) runs `cargo test`-equivalent `node --test`
across the workspace on macos-latest. 24 tests pass locally only because THIS Mac has a live
18-agent board / tmux; on a clean runner they read live machine state and fail. Make them
CI-safe so the workflow can land.

## Decision: HERMETIC via existing seams where clean+verifiable, SKIP only where no seam.
The card recommends (d) blanket-skip, framing (a) hermetic as "a much larger effort (full
sandbox)". Reading the code, that is not so for the BOARD dependency: `status.setPaneSource(fn)`
is an existing, widely-used test seam (dozens of sibling tests arm it). The 24 board-dependent
tests are simply the ones that FORGOT to arm it. Arming it (an empty board by default) makes
them hermetic AND they keep RUNNING on CI (a skipped test tests nothing there). Strictly better
than skip, and cheap.

**Local verification method (this is the key — it removes the machine the card worries about):**
run the fixed file with `AGENT_WORKFORCE_TMUX_BIN=/nonexistent/tmux`, which makes a live
`paneRoster()` THROW (control-verified). If the tests still pass under that proxy, they never
touch the live board -> hermetic, proven without a real runner.

For non-board live deps (homedir / process) I use the right seam where one exists (the test
files already sandbox HOME/DATA), else SKIP with a printed reason. **Assert the total skip
count** so a skipped test cannot silently drift into a false green (the card's key requirement).
