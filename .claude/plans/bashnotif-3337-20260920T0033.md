  genuine compact notification (verified by screenshot).

  That sentence was the on-screen mention of "Login Items", which a 0.6.42 browser-check control

  underlying bash background-activity grant is still a Login Items thing (macOS); only the on-screen
  copy no longer names it. Updated the S3-art comment (web/index.html ~10161) accordingly.
