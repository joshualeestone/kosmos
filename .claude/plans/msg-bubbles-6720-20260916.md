# msg-bubbles-6720 - 6.72 message-bubble rework (#3130 followup, Josh 6.72)

## The ask
Josh's 6.72 feedback on the room message dialog (posted in #chaoskosmos-design with a Tessa mockup as the target), six changes:
1. Fix the bubble tail. The user bubble's tail looked like "two transparent objects colliding making a weird triangle." Replace with a clean iMessage-style wing at the bottom corner, pointing toward the avatar, on both bubbles.
2. Timestamp inside the bubble, bottom-right.
3. Agent name inside the bubble, at the top. The user's own bubble gets no name.
4. Avatar bottom-aligned with the bubble (not centered).
5. Remove the inline "Placed with X, Y, Z ... could not be reached" delivery notices ("I don't need to know who the message was pasted to or sent to").
6. Clicking the agent name or avatar goes directly to that agent (both consolidated and tab views). No underline, no link styling, just active.

## What "finished" looks like
- Room bubbles render like the Tessa mockup: agent name bold at the top inside the cream bubble, timestamp small and muted at the bottom-right inside, avatar bottom-aligned by a clean wing, user bubble blue with no name and its own bottom-right timestamp, no inline delivery receipt.
- The user (translucent) bubble's wing shows no double-tint seam.
- Clicking an agent's name or avatar opens that agent (openDetail with PJ_CURRENT so back returns to the project); no underline.
- render-room-msgbox-2806.js is rewritten to assert all of the above and passes light + dark.
- render-room-scroll.js (Renet's #1147/#3200 oracle) stays green: the geometry change does not reintroduce the scroll bounce.
- Full node suite green.

## The change (web/index.html, pjMsg / pjRoomRow + .msg CSS)
- Render: name and timestamp move INSIDE `.msg-bd` (`nameEl` = `<b class="msg-nm" data-open-agent>` for agents only; `timeEl` = `<span class="msg-t">` last). The `.msg-h` header above the bubble is gone. The `receipt` (`.delivery`) is no longer rendered (the dead receipt/cls/states computation is removed). Agent avatar carries `data-open-agent`.
- CSS: `.msg { align-items: flex-end }` (avatar bottom-align). The tail becomes a WING: colored `::before` (`background-color: inherit`) drawn OUTSIDE the box (negative offset) so a translucent fill composites once and never double-tints, plus a `--k-bg` `::after` mask that carves the wing to a point. `.msg-nm` (block, bold, top) and `.msg-bd .msg-t` (block, right, bottom). Pointer cursor on `.msg-nm` and the agent `.msg-av`. Dead `.msg-h` CSS removed.
- Click handler: a delegated `#pj-room` listener opens `[data-open-agent]` via `openDetail(sessionName, undefined, PJ_CURRENT)`; a dedicated attr means a reaction or body click never triggers it.
