# winc2-8378 (kosmos#8378, cluster 2 of 4)

**Problem.** 59 engine test files (connect.willinstall-dryrun-1556 to openaiaccounts) failed on GitHub's Windows runner (Mona's list, card comment 7235171056). Measured again before any change: 59/59 red (run 46115809463).

**Shared causes, fixed rather than skipped:**
- runner stubs that were `#!/bin/sh` scripts or `/bin/echo`: now `test-support/runnerstub.js`
- HOME without USERPROFILE (`os.homedir()` reads USERPROFILE on Windows)
- a plist-only job fixture: now `jobfixture.useJobStore()` (the stand-in Task Scheduler)
- POSIX path literals for platform-neutral subjects: now `path.join`
- JSON built by string concatenation over a backslash path
- the roster read through tmux: now `status.setPaneSource`
- shell probe scripts: now node stand-ins

**Skips, each naming what Windows lacks:** POSIX file modes (the house `NO_POSIX_MODES`), systemd and the Linux board, tmux, mkfifo, signals and process groups, launchctl, the Mac's Secure Enclave signer (kosmos-se), a double quote or a newline in a file name, absolute POSIX paths, and symlinks (they need elevation or Developer Mode on Windows; GitHub's runner is an admin, so they passed there but would fail on a person's laptop). Where a folder link is only the fixture, a junction stands in (no elevation needed). An arm that uses chmod 0o000 to make a file unreadable skips too: Windows only marks it read-only, so the arm would pass by another rule. Where the subject exists on Windows but the stand-in is a shell script, the skip says so and names kosmos#9269 (#8456 is closed).

**Real Windows bugs, carded and NOT skipped:**
- #9270, the Muse turn log stops for good: ftruncate on an O_APPEND handle (musefront.test.js stays excluded)
- #9271, Undo after an add leaves the Scheduled Task (disconnect-agent.test.js has no win32 branch and stays off the Windows job)

**Decided, not a bug:** feedbacksend.sandboxed() has no Windows temp root by design (its own comment, #5294 review 3), so that arm skips with that reason.

**tools/windows-tests.js:** 49 files join ALSO, the Windows job's selection; each ran with passing tests and no failures on windows-latest. 9 files join HOST_BRANCH_EXCLUDED: the seven Linux-only files, musefront (#9270) and create.live-gate. Each of those entries carries its file's own skip reasons verbatim, as windows-tests-1777 requires. disconnect-agent has no win32 branch, so it needs no entry; it stays off the Windows job until #9271 lands.

**How it was made.** Five helper agents drafted the test edits under one written brief (test files only, no production code). I read the whole diff, repointed nine files from the closed #8456 to #9269, fixed blockdrop's roster and feedbacksend's arm, and wrote the windows-tests.js entries myself.
