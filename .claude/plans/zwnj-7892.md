# zwnj-7892: a zero-width joiner or non-joiner inside a Persian or Indic word is spelling (kosmos#7892)

A leftover carried to #7892 from #7909's review: `shownText` escaped and marked every ZWNJ (U+200C) and ZWJ
(U+200D), so ordinary Persian and Indic names read as unusual, and a flag that fires on ordinary names stops being
read.

## Change (engine/seadmin.js)
`joinerInWord`, after IDNA's ContextJ (RFC 5892 A.1, A.2): a ZWJ or ZWNJ is kept as it is, and does not mark the
text, only where it can change how the word looks: straight after a virama, with a letter of the virama's script
before it and after the joiner (Devanagari, Bengali, Gurmukhi, Gujarati, Oriya, Telugu, Kannada, Malayalam, Sinhala;
not Tamil, which has no half forms); or a ZWNJ between an Arabic letter that joins forward (Joining_Type D) and one that
joins back (R or D), harakat allowed before it, by a table from ArabicShaping.txt (tatweel and superscript alef
excluded). Anywhere else it is escaped and marked as before. Syriac and the other joining scripts are left out on
purpose. The source carries no raw joiner.

## Review round 1 (opus)
- BLOCKER: the first rule (any joiner between two letters of one script) let through joiners that change nothing on
  screen (after an alef; a ZWJ between Arabic letters; Indic with no virama), so look-alike pairs read normal. Fixed:
  ContextJ, with each shape as a must-mark test row.
- WARNINGs: the header comment and the plan understated the gap (fixed with the rule); no test had two joining scripts
  either side (added; the reviewer's drop-same-script mutant now fails).
- NITs: a foreign virama (fixed: the virama must share the letters' script); the scripts list named as partial.

## Review round 2 (sonnet)
- WARNING: the tatweel (U+0640, Joining_Type C) and superscript alef (U+0670, T) were inside the accepted ranges, so a
  ZWNJ beside a tatweel passed. Fixed: both excluded; rows for a tatweel either side.
- WARNING: Tamil has no half forms, so a joiner after its virama changes nothing. Fixed: Tamil dropped; the comment
  says "can change" and names the font residual (a font with no conjunct shows the two alike).
- WARNING: the rows did not exercise the table. Added: dal before, a ZWNJ then a ZWJ, a virama at the start, Tamil,
  an R letter after (allowed), an Arabic-extended D (allowed). Mutants on the tatweel carve-out, Tamil and dal: red.
- NITs fixed: harakat are skipped before the ZWNJ only (comment says so); the header bullet rewrapped.

## Review round 3 (opus)
- WARNING: most of the R table was unpinned (the reviewer checked every entry against ArabicShaping.txt and found it
  right). Fixed: a must-mark row per R group (U+0691, U+06C4, U+075B) and an Arabic Supplement D row (U+0750); four
  table mutants (each group, and the Supplement range) now red.
- CONVENTION: the plan still listed Tamil and an old test list. Fixed.
- NITs fixed: long lines wrapped; the known false positives named in the comment (nukta before the virama, Bengali
  ya-phala, a chillu at a word's end, a mark after the ZWNJ). Kept: the other Joining_Type T marks are not skipped
  (conservative: marked, never hidden).

## Review round 4 (sonnet)
- WARNING: only Devanagari and Bengali of the nine virama scripts were pinned as kept. Fixed: one half form per kept
  script (Gurmukhi, Gujarati, Oriya, Telugu, Kannada, Malayalam, Sinhala), each with an NFC control; virama typo and
  deletion mutants red.
- NIT fixed: the "mark after the ZWNJ is marked" false positive is pinned by a row, so changing it is a decision.

## Review round 5 (opus)
- WARNING: Sinhala forms a conjunct only on ZWJ, so a ZWNJ after al-lakuna changed nothing and passed. Fixed: Sinhala
  keeps only the ZWJ; a must-mark row; the mutant red. Named, not fixed: a letter with no half form (Devanagari nga,
  Telugu ka) looks the same with ZWJ, ZWNJ or neither after its virama in any font. ContextJ allows it, and knowing
  which letters have half forms is font data this code does not hold; it is stated in the comment as a residual.
- NITs fixed: test comments moved to their rows; the pinned false positive notes that only its text half pins the
  joiner rule; the header bullet reflowed.

## Weakest premise
That the no-half-form residual is acceptable: two names differing only by a joiner after the virama of such a letter both read normal. And that the Arabic Joining_Type table (R and U sets) is complete for the ranges it accepts. A letter wrongly left as D
would let a ZWNJ after it through unmarked although it changes nothing; the ranges are kept narrow for that reason.
