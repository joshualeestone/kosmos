# sonnet55-4439: add Claude Sonnet 5.5 to Kosmos (#4439)

## Finished means
- The Create Agent / AI Settings picker offers "Claude Sonnet 5.5" (`claude-sonnet-5-5`), ahead
  of Sonnet 5, and Sonnet 5 stays available and stays the default.
- A running Sonnet 5.5 agent's card names it "Claude Sonnet 5.5" (status.js MODEL_NAMES).
- Its context ring measures against 1,000,000 tokens, shown as assumed.
- Its tokens count in the Equivalent Token API Cost (USAGE_MODEL_PRICES), not as unpriced.
- A test per surface. The picker, launch, name and price tests fail on main (measured); the
  context-ring test is a PIN that passes on main, because the ring needed no code change.
  Plus the pinned order and count tests.
- The commit carries a `Browser-check:` trailer (web/index.html changes price data only), or the
  #1720 browser-check gate fails the branch (review 1, B1).

## Source of truth (posted on #4439 before coding)
Claude Code 2.1.284's own model catalog (`~/.local/share/claude/versions/2.1.284` on Mortals):
- id `claude-sonnet-5-5`, display_name "Sonnet 5.5", SONNET_NAME "Claude Sonnet 5.5".
- context.window 1e6 (native_1m); max output 128,000.
- pricing tier_2_10: input 2, output 10, cache_write_5m 2.5, cache_read 0.2 ($/MTok), the same tier
  as claude-sonnet-5. The same catalog gives claude-opus-5-5 exactly the published rates Kosmos
  already carries (4/20/0.20), which is why it is trusted for the price.

## Decided, and why
- Default stays Sonnet 5: the card asked to add Sonnet 5.5, not to change the pre-selected model.
  One line to change if Josh wants it.
- The context ring needed no code: ASSUMED_LIMIT_MODELS already matches claude-sonnet-*. A test pins
  the size (1M, 10% at 100k tokens) and the "assumed" label, not only that a number appears.
- Placed ahead of Sonnet 5 as the newest of its tier, as #3459 placed Opus 5.5 ahead of Opus 5.
- No Kosmos Guide model list exists in the tree: a grep for "Sonnet 5" and claude-sonnet-5 in docs, web
  and engine found no other model list or price table (the other hits are comments and browser-check
  fixtures).

## Weakest part
- The price comes from Claude Code's catalog, not from claude.com/pricing directly. The catalog
  matched the published Opus 5.5 rates, which is the evidence it is right, not proof.
