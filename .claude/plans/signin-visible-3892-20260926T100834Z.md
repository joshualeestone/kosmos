# signin-visible-3892: Sign in again never hides on the phone chat

Addresses #3892 (#3882's open risk 3, accepted by Liu Kang as a follow-up; Liu Kang m1019).

## Finished looks like

On the agent's phone chat, with every header note showing (a usage-limit quote, a stale-instructions
note, Sign in again), Sign in again is on screen and takes its own tap at 375x667, 393x852, 412x915 and
430x932 without the person scrolling the header, and for a swarm agent whose sign-in stopped (the case
where two actions really share the header) Stop now stays uncovered too. The desktop layout is unchanged.

Correction (review round 4): #3892 names Start this agent and Sign in again together, but they never show
together today: Start shows for an agent that is off (refreshStartAffordance), and a stopped sign-in
(auth_failed) counts as on (CARD_ST). The Start part of the floor is kept as a defence, labelled so; the
real two-action case is a swarm's Stop now with Sign in again.

## Measured before (origin/main, Chromium touch)

Sign in again sat below the capped header's fold at EVERY phone size (not only an SE): it is the last
note, after the quote. Start this agent was on screen at every size (it comes before the notes).

## Change (CSS, phone chat block only)

- `#d-reauth:not([hidden])` is pinned to the bottom edge of the capped header (position: sticky), on the
  page's ground (--k-bg) with a fade above it that shows the block goes on, 44px tall. DOM order, so the
  keyboard and screen-reader order, is unchanged. `:not([hidden])` because display would otherwise
  override the hidden attribute.
- While Sign in again AND a swarm's Stop now show (a swarm agent whose sign-in stopped, the two-action
  case that really happens), the cap has a 190px floor: Stop now is never under the pinned button and
  scrolling brings its whole warning (up to 116px on an SE) into view above it. A 152px floor is kept for
  Start this agent as a defence (the two never show together today). Both floors are held to 30% of the
  visible height (a phone held sideways keeps its conversation). For a swarm agent whose sign-in stopped the name
  row stays one line (the task sentence is not shown, the badge whole, the name ellipsized).
- A 16px gap above the pinned button keeps the quote's last line clear of the fade once the block is
  scrolled to its end.

## Rejected

- Growing the cap by 44px whenever Sign in again shows: it took 44px of conversation from every phone,
  and the larger phones already fit both actions.
- CSS `order` to move Sign in again up: a visual order that differs from the DOM (#1017's defect).
- Moving the button in the DOM for every layout: changes the desktop, where it sits under the quote it
  answers.

## Weakest parts, named

- While a swarm agent's sign-in has stopped, the conversation gives up about 70px on an SE and at most
  37px on larger phones (32px on an SE for the defensive Start case). In the worst case measured (the
  "Kosmos is not answering" banner plus every note) the SE had almost no conversation on main either
  (4px); the header steps aside while typing, so writing gets the room back.
- The pinned button lies over the end of the quote until the block is scrolled; the quote is still
  readable by scrolling the block.
- While a swarm agent's sign-in has stopped, its name row is one line so the floor holds whatever the
  name's length: the task sentence is not shown (the state badge and Sign in again say it), the badge is
  whole, the name ellipsizes (it is on Profile in full).
- 375 is the smallest portrait width covered (#718's sizes); a 320px first iPhone SE is not measured.
  Sideways, the floors are held to 30% of the height, so Stop now's whole warning may need a scroll past
  the pinned button there.
- Measured while adding the sideways arm: at 640x360 the chat-first phone layout already leaves the
  conversation at 0px and the composer below the screen, with or without Sign in again (on main too).
  Sideways phones were outside #3882's scope; this PR only keeps its own cost there bounded. Follow-up to
  raise with Liu Kang.
- DECIDED (round 8): while a swarm agent's sign-in has stopped, the pinned Sign in again lies over Stop now's
  warning until the header is scrolled; see the Review list. Weakest part: someone who taps Stop now
  without scrolling has not seen the warning. What would change my mind: Liu Kang or Josh ranking the
  warning above the recovery button in this state.
- Touch is emulated; WebKit is an engine approximation, not Safari.
