# Org chart: green glow for working, red glow for needs-you (#2839)

## Ask
Josh, 0.6.57 live review, 2026-09-11: "It would be awesome if we could see a working state on the
org chart view, like maybe a green glow behind them? and a red glow to ones that need you".

## What finished looks like
On the org chart, each working agent has a green glow behind its node and each needs-you agent a red
glow. Idle/paused/stopped/unknown/restarting agents stay quiet (no glow). The colours match the
agent status colours used on the cards (green = working, red = needs-you) in BOTH themes, so the two
views cannot drift.

## Approach (web/index.html only, existing data + state model)
- The org node already computes `needsYou = cardStOf(a).st === 'attn'` and renders the needs-you
  corner badge from it. Add `working = cardStOf(a).st === 'working'` and a `glowCls`
  (`' onode-attn'` when needsYou, else `' onode-working'` when working, else `''`). Append it to the
  `.onode` button class.
- CSS: a soft box-shadow halo behind `.onode .face` per state. Light theme uses the same rgba the
  cards use (working `rgba(47,125,90)`, needs-you `rgba(179,38,30)`). Dark theme swaps to the
  lighter state family the rest of the UI uses in dark (working `rgba(121,197,157)`, needs-you
  `rgba(255,140,130)`), defined under BOTH the prefers-color-scheme media query and
  `:root[data-theme="dark"]`, mirroring how `.onode .face`'s own dark background is defined twice.
  Glow only, no hard ring, so it sits behind the context gauge (`.oring`). The box-shadow renders
  outside the disc, so the face's `overflow:hidden` does not clip it.

## Decisions / weakest premises
- `working` and `attn` are mutually exclusive via single-valued `cardStOf`, so the ternary order is
  defensive, not a live precedence. A needs-you-while-active agent (#2146 activeWhileWaiting) reads
  st 'attn' and glows red, which is the signal that matters; the working glyph still rides alongside
  it elsewhere.
- Only two states glow; everything else stays quiet, matching the card rule that red covers one
  state ("impactful because it is rare"). WEAKEST PREMISE: if Josh wants paused/blocked to glow too,
  widen the map; the cards deliberately do not.
