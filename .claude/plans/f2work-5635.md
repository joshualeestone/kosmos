## Known costs of the codex rule (review round 1), stated in the code comment too
- A later turn still running after the writing turn ended reads current however long it runs (no cap).
- A codex agent in a blocked or needs-you wait records no automatic idle (selfreport refuses it), so it reads current.
- A codex agent whose turn-end reports stopped arriving reads current.
- A short prompted turn (a community prompt) ending after the summary makes it stale again, so GPT clears on Josh's
  next run only if no second turn has ended by then.
Chosen over never excusing codex (the repro). A real fix needs codex to report turn starts; not available today.
The line for this case reads "current: no later turn has ended since it was written", not a minute count.
- (round 2) A manual idle report from a codex agent counts as a turn end; with no turn ended since the summary, the
  writing turn reads current however long it runs.
- (round 2) For runners that report working: the board's screen read no longer stands in for a lost working report,
  so such a member (last report idle) reads current however long it has been working. This is Josh's rule.
- (round 3) A codex agent's own busy report after the summary (kosmos report working, needs_you, blocked) is reported
  work: stale. Idle rows within 2 min of each other count as one turn end (an automatic idle and a manual one together).
- (round 3) Not checked: that every bridge for gemini, grok, antigravity and muse emits working at turn start; with the
  screen read gone, a bridge that misses it reads current. Worth one check per family before release.
- (round 5) Bounded: a codex summary is never excused past six rhythms (24 h) of clock time, so a seat whose turn-end
  reports stopped arriving cannot read current for ever; the 18 h GPT repro is under it.
- (round 5) The bridge question is smaller than stated in round 3: a reviewer read the gemini (BeforeAgent), grok
  (UserPromptSubmit) and antigravity/muse (PreInvocation) bridges and each sends working at turn start. What remains
  unmeasured is a hook that never fires on a live agent (for example one launched before its bridge was installed).
- (round 9) Decided: no clock cap for the runners that report working. Their idle is a real report, and Josh's own
  0.7.48 report cleared an idle Meta seat at 23h 24m: a cap would flag exactly the idle seats the ask clears. The codex
  cap is a backstop for turn-end reports that stop arriving, which a working-reporter's idle report does not need.
- (round 9) A codex restart (started/stopped rows) after the summary is neither busy nor a turn end, so a restarted
  seat stays current until a second turn ends (within the 24 h cap).
