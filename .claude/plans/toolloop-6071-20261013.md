# toolloop-6071: slice D1 of #6071 (#5154 slice D), Claude Code

The card's plan is comment 6152129327 on #6071; this is increment D1 of it.

## What D1 does
A Claude Code agent's failed tool call (the PostToolUseFailure hook) is sent to the board as a digest, and the board
counts the SAME failure repeating inside one turn. Nothing is raised to the person yet (that is D2). The first time a
run reaches the threshold is logged, so the threshold can be read against real boards first.

- engine/reporthook.js: PostToolUseFailure joins HOOK_EVENTS (wired into every account's settings by ensureWired, merge
  only). A Claude Code too old to know the event ignores it ("unknown hook event; entry ignored", in 2.1.296).
- install/kosmos-report-hook.sh: the PostToolUseFailure branch. The signature is a hash of tool + tool_input (key-sorted)
  + the error's first line, made in the hook, so the input never leaves the Mac. Without jq: the whole payload with its
  tool_use_id removed. An interrupt is not sent. It calls `kosmos tool-failed` (3 s bound, always exit 0).
- install/kosmos: `kosmos tool-failed <tool> <sig> [<error>]`, internal (no help row; MAC_INTERNAL_VERBS).
- engine/kosmos-report-hook.js: the Windows twin (failureRequestFor, toolFailed), POST /api/toolfail itself.
- server.js: POST /api/toolfail, sender resolved as POST /api/report resolves it (resolveAgentSender, token first, the
  same pane refusal on an enforcing board); in AGENT_TOKEN_ROUTES (pinned in server.agent-token-sender-570.test.js).
- engine/toolloop.js: the per-agent run at store/toolloop/<key>.json. Consecutive identical signatures count; a
  different signature starts a new run; a turn end (an idle, stopped or started self-report newer than the run's last
  failure) starts a new run. LOOP_AT = 5. Forgotten on create, remove and delete, like stuckterminal.

## Rejected
- Reading the transcript's is_error results on a tick: polling every agent's transcript, versus a hook pushed only on a
  failure that carries the error.
- Counting in the hook and raising through `kosmos report needs_you`: Stop clears a standing auto needs_you at the end
  of every turn, so a loop would vanish the moment the agent gave up.
- Sending the raw payload: a failed Write carries a whole file in tool_input.

## Evidence for the weakest premise (that failing Bash calls reach PostToolUseFailure)
Every non-zero Bash exit in this agent's own 2.1.296 transcript (7 of 7) is a tool_result with is_error true, so Claude
Code treats them as failures. That the hook fires on that path is not yet measured; D1's records measure it.
