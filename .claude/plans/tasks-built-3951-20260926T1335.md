# tasks-built-3951: "Built but waiting" gets a real state (#3949 follow-up)

Addresses #3951. Josh's six tiles (#3949, 2026-09-26) were: Needs Your Decision, In progress, Assigned but not
started, Unassigned, Built but waiting, Completed. #3949 shipped five, because nothing on a task recorded "built".

## The call
- An agent (or the person) marks an open task built: `kosmos task built <project> <n> ["what is left"]`. The board
  stamps `builtAt`, `builtBy` and an optional `builtNote` on the task and records a `built` event in its history.
- Cleared by: `kosmos task built <project> <n> --clear` (an `unbuilt` event); closing the task (the person's
  "it is live, done"), which drops the stamp; and adding a new part (new work means it is no longer all built).
- `tasks.taskState` order: closed, decision, built, nobody, working, assigned. An agent needing the person outranks
  "built" (the red tile is the one the person acts on). `nobody` sits after `built` so a built task whose agent was
  since unassigned still reads as built.
- The Tasks page adds the tile in Josh's slot (between Unassigned and Completed) and a group with its sentence; a
  built row shows its note. The view still renders the engine's word and never computes it.
- Agents learn the command from their managed instructions block (projects.blockBody), beside the lines that teach
  `task <n>`; without that no agent would ever mark anything and the tile would read 0 forever.

Rejected:
- Deriving "built" from evidence (a merged PR naming the task): no task records its PR, and a guessed count is what
  #3949 refused to show.
- Clearing on a release: Kosmos has no release event a task can see. The person closes it when it is live.

Weakest premise: agents will actually run `task built`. The instructions line teaches it; nothing enforces it.
Would change the design: Josh wanting "built" to clear only on a verified release (then the release step needs a hook).

## Change
- engine/tasks.js: setBuilt, clearBuilt; setClosed and addPart drop the stamp; taskState returns `built`.
- server.js: POST /api/project/:id/task/:n/built (body `{ note, clear }`); `builtBy` from the agent token, else
  `operator` from the screen; 409 on a closed task; the note capped and one-lined.
- install/kosmos and tools/windows/kosmos-cli.js: `task built`, sending the agent token.
- engine/projects.js blockBody: one instructions line teaching the command.
- web/index.html: TSK_GROUPS `built`, its colour token, a row line with the note.
