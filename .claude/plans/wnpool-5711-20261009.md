pick the top 4 or 5 things cumulatively from the last time that we actually had a release roll to production." Starts
with 0.7.36; 0.7.35 was promoted as is (14:43).

## Change
- release/whats-new-pool.json: every highlight once, { title, line, icon, platforms?, rank, since, status }; status
  pending (not yet shown to prod users), shown (a prod release showed it; shownIn), held (never shown: Josh's holds).
  Seeded from git history of web/whats-new.json, 0.7.31 to 0.7.35 (17 items; 0.7.29's two arrived through 0.7.31, so
  their `since` says 0.7.31): conversation mode "Hear new agent
  messages read aloud" HELD (Josh 10:49, #5699); "Agent cards show the last community post" SHOWN in 0.7.35.
- tools/whats-new-pool.js `build <version>`: the top 5 (or --max) pending by rank, newest first on a tie, written to
  web/whats-new.json, checked by engine/whatsnew.js problems() (the same rules the cut's step 1b-ii enforces); refuses
  (exit 3) rather than writing an empty window. `shown <version>`: after a PROD promote, the titles that version showed
  become shown and lastProd moves; a held item stays held.

## Decided
- **The ranks are my call** (1 = community replies end to end, 2 = Haiku 5.5, 3 = done-when, 4 = agent as one file,
  5 = stuck agent, ...). Change a rank in the pool file; the next build follows it.
- **"Since the last PROD release" read as "not yet shown to prod users".** Prod jumped 0.7.28 -> 0.7.35 and showed one
  highlight, so 0.7.29 to 0.7.34's items are still pending and 0.7.36 can show them. WEAKEST PREMISE: a literal reading
  ("released after 0.7.35") would drop them; the status field makes either reading a data change, not a code change.
- Rejected: per-version lists merged at show time on the board (Josh: ONE list, decided at cut time); hand-merging the
  file at each cut (the card: reuse a durable record).
- Not in this change: running `shown` from the promote script (promote-channel.sh / the promote recipe), and the cut
  calling `build`. Until then the release owner runs `build` before the What's New PR and `shown` after a prod promote.
