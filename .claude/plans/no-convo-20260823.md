# no-convo: the room-conversation box leaves the agent page

**2026-08-23, Josh 12:38:** "i want to remove the conversation box... the only
thing i want there is the talk to agent box... i've asked for this to be
deleted multiple times over and over."

## What finished looks like

- The "Conversation" box on the agent page (every message said to this agent
  across every room, plus the "does not know how to message your other agents"
  sentence) is deleted: markup, `paintConversation`, `convoRow`, the
  `CONVO_LOAD` counter, the reset on open, the gap paint inside
  `loadInstructions`, and its CSS. Not hidden, not gated.
- `/api/agent/:name/conversation`, which existed only to feed it, is deleted
  with its tests. A room's messages are read in that room.
- The person's own thread with the agent (the talk box, `#d-dmthread`,
  `#d-say`) is untouched and is the whole of the Talk section.
- The project room's own "Conversation" heading (the room thread) is untouched.
- Tests that were only about the box or the route are deleted; tests that had
  a `convoRow` arm beside other arms keep the other arms.

## Why it survived until now

Each earlier ask was read as "make it clearer" and the box was improved (#192
closed on labelling the rows). The agent-page mock then drew it because it was
what shipped, and the sectioned page carried the mock. A removal ask that
survives into a redesign reads as designed in.
