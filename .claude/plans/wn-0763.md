The cut refuses unless web/whats-new.json is for the version cut (release.sh step 1b-ii); main's is for 0.7.62. Built
with `node tools/whats-new-pool.js build 0.7.63` (#5711: the top five pending since the last prod release). Mac prod
still serves 0.7.61 (0.7.62 waits on its promote), and the pool already records lastProd 0.7.61, so nothing is marked
shown and 0.7.62's items stay eligible.

## The built list (top five)
Browse an agent's files; Crop a picture before saving it (new); A team map for each project; Files show a
fingerprint (new); Agents are told how to finish a task. Mac 5, Windows 5. "See which agent changed a file" (mac only,
11.6) and "A paused room says why" (11.8) drop out of the five and stay pending.

## Decided
- New pool item "Crop a picture before saving it", rank 3.5, since 0.7.63: kosmos#6722 (#6828) opens cropPicture for
  every picture chosen for an agent (its page, a new agent) or for the person (web/index.html, three callers, no
  platform gate). The line says "still picture" because a GIF is returned as chosen without the editor (cropPicture's
  first line: cropping would stop an animated one moving). A picture the browser cannot open also skips it; the line
  does not claim otherwise for that case, as "opens an editor" is what a person sees for any picture that shows.
- New pool item "Files show a fingerprint", rank 6, since 0.7.63: kosmos#6761 shows 12 hex of a file's sha256 on the
  Files screen and on the project-folder list of a project's Documents screen. The line claims those two and "beside
  files", never "each file", because review 1 found three gaps: the Documents screen's "From this conversation" list
  shows no fingerprint; engine/filehash.js skips a file over 512 MiB and a cloud-only placeholder of 1 MiB or more; and
  in a large folder a fingerprint can arrive after the view stops refilling (about 30 s). The narrow Files panels (the
  agent page's, the project rail's) show it only on hover, which is why the line names the screens, not the panels.
  No platform gate in filehash.js (its kernel flags are undefined-safe on win32).
- Not added: Token Usage counting since install (#6829), the agent tile wording (#6716), resumable attachment
  downloads (#6805), the company reviewer notice (#6817). Real but smaller; they can go in the pool later.
- Not announced: Kosmos+Kids family changes and the iPhone app tabs, which are not launched.

## Weakest premise
The two ranks, set here by the release owner alone. Second: the screen names. Review 2 found "Documents folder list" is not a label on screen; the line now uses the
words a person sees: an agent's Files screen (built non-compact, so the fingerprint is on the row) and a project's
Documents screen. Review 3 found the "In the project folder" label is shown only when the conversation has files
(the docs-seg switch is hidden otherwise), so the line names no list: "the files in their folders" is true of both
screens and leaves out the conversation's attachments without naming a label that may not be there.
