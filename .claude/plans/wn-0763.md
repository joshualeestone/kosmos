## Decided
- New pool item "Crop a picture before saving it", rank 3.5, since 0.7.63: kosmos#6722 (#6828) opens cropPicture for
  every picture chosen for an agent (its page, a new agent) or for the person (web/index.html, three callers, no
  platform gate). The line says "still picture" because a GIF is returned as chosen without the editor (cropPicture's
  first line: cropping would stop an animated one moving). A picture the browser cannot open also skips it; the line
  does not claim otherwise for that case, as "opens an editor" is what a person sees for any picture that shows.
- New pool item "Each file shows a fingerprint", rank 6, since 0.7.63: kosmos#6761 shows 12 hex of each file's sha256
  on the Files and Documents screens (the narrow lists show it on hover). "stored on this computer" because
  engine/filehash.js skips a cloud-only placeholder of 1 MiB or more, which has no fingerprint. No platform gate in
  filehash.js (its kernel flags are undefined-safe on win32).

  downloads (#6805), the company reviewer notice (#6817). Real but smaller; they can go in the pool later.
