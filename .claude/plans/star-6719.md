# star-6719: a star on each agent tile pins that agent to the top

Card: #6719. Josh, #admin 2026-10-20 08:44: "lets add a small star functionality to the top right of these tiles so
like if I starred you it would basically pin you to the top".

Stacked on `tiletext-6716` (#6716 changes the same tile renderer); rebased onto main when #6716 merges.

## Done when
- Every agent tile has a star in its top-right corner, and every list row has one at the right of the name: an
  outline when off, filled gold when on, labelled "Star <name>" / "Unstar <name>".
- Clicking it (or Enter on it) stars or unstars that agent without opening it; a starred agent sorts first in every
  sort order, and the starred group keeps the chosen order among itself.
- Stars are kept on the board, so they hold across restarts and on every screen that views this board (Kosmos+
  remote included); only the person can set them.
- The corner star does not overlap the unread badge, a list row's star does not cover the name, and on a touch
  screen the star is a 44 px target.

## Decisions
- **Kept on the board, not in the browser** (`store.ROOT/agent-stars.json` via GET/PUT `/api/agent-stars`): the card
  asks for every computer they view it from. Rejected: localStorage (one browser only). Weakest premise: a person
  with two Kosmos computers has two boards, and stars them separately on each.
- **By session name**, the board's unique key, not the display name (which can change).
- **A set, not an order**: within the starred group the chosen sort applies, as the card asks.
- **Another computer's agents (the "other computers" groups) take no stars**: a session name there names a different
  agent, and these stars are this board's.
- **Drawn at once, confirmed by the board, put back on a refusal.** A newer read or write always wins over an older
  answer (`STARS_SEQ`). Stars are re-read every 30 s so one set on another screen shows here.
- **An unreadable stars file is never overwritten** from an empty reading (that would drop every star); the board
  answers ok false and refuses a star with a 500 until the file is fixed.
- **One repaint for the sort control and the star** (`repaintAgentOrder`), so they cannot disagree about order.
