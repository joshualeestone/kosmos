## Decided
- One new highlight in release/whats-new-pool.json, since 0.7.65: "A message that did not go can be sent again"
  (#6720, PR #6763), icon chat, rank 4.5 (first: Josh asked for it by name, #admin 2026-10-20 08:49). Its line says
  only what main does: a COULD_NOT row in an agent's direct thread draws "Message failed to deliver, try again." under
  the bubble, and try again sends the same words once into the same row (retry_of). A reply, menu answer or file says
  "Message failed to deliver." with no try again, and the button is offered only on the person's newest message
  (sent again behind a newer one it would arrive out of order) and only on a row recorded after #6720 (retryable). So
  the line names "your latest message" and "plain words" (review 1), and "an agent's chat", since the line is drawn
  in the agent's direct thread only.
- Built with `node tools/whats-new-pool.js build 0.7.65`. Prod still serves 0.7.63 (the 0.7.64 GO is pending), so
  0.7.64's highlights stay pending and lead the list after the new one: the two task highlights, "See which agent
  changed a file" (Mac only), "A paused room says why". "A project shows each member's role" (rank 12.5) drops to
  sixth.
- Not chosen: everything iPhone (#7008, #7010, #7016, #7030, #7034, #7042, #7045, #7046, #7050: the phone app, not the
  board); `kosmos records` and `kosmos task list --all` (#6994, #7057: agent-facing CLI); the sealed-room key section
  (#4658: waits on a coordinator deploy); the Windows Start-menu wording (#6985: small).
