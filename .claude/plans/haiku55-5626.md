# haiku55-5626: add Claude Haiku 5.5 (claude-haiku-5-5), Mac and Windows

**Ask:** Josh, #admin 2026-10-08 17:43. Add Claude Haiku 5.5. Josh, 17:44: "Let's not delete any other Claude models that we might have listed either."

**Facts and sources (2026-10-08):**
- **Id:** `claude-haiku-5-5`. Anthropic's models page lists it as the Claude API id and alias, dateless (its own pinned snapshot), released 2026-10-07. The installed Claude Code 2.1.295 names it 10 times in its binary.
- **Context window:** 1M tokens (models page), knowledge to June 2026.
- **Price:** priced by prompt length (platform.claude.com pricing).
  - Prompts up to 100,000 tokens: input 0.10, 5-minute write 0.125, cache read 0.01, output 0.50 per million tokens.
  - Prompts over 100,000 tokens: five times that.

**What changes (shared engine and page code, so Mac and Windows alike):**
- `engine/create.js`: the picker entry `haiku55`, placed ahead of Haiku 4.5 as the newest Haiku. Haiku 4.5 and every other model stay, and the default stays Sonnet 5.
- `engine/status.js`: the readable name "Claude Haiku 5.5". `limitFor` gives it the 1M window, still marked as assumed; Haiku 4.5 keeps 200K.
- `engine/usageprice.js` and `web/index.html` USAGE_MODEL_PRICES: the base-rate row, identical in both (engine/usageprice.test.js compares them).

**Decided:**
- **Base rate, not the long-prompt rate:**
  - A usage day carries no per-request prompt size, so one row stands for both tiers.
  - The base rate is the published headline price ("From $0.10 / input MTok").
  - Weakest premise: an agent whose prompts are mostly past 100,000 tokens is under-estimated, by up to five times. A split by prompt size needs per-request data the usage scan does not keep.
- **Rejected: leaving it unpriced (null).** The page would then say no published price exists, which is false.
- **Rejected: the long-prompt rate.** It over-states every short-prompt day.

**Not changed here (noted on #5626):** the published Sonnet 5.5 cache-read price is now 0.10 (0.05x of input), and both tables say 0.20. A separate fix.

**Tests:**
- `engine/create.test.js`: the picker has Haiku 5.5, keeps every model it had, and the default is unchanged. An agent created on `haiku55` launches with `claude-haiku-5-5` and is named "Claude Haiku 5.5", with Haiku 4.5 as the control. The model count is 9.
- `engine/model-sort-order-2284.test.js`: the order.
