## Change
`usedAsSelector(token, text)` in tools/bc-pr-select.js. The selector route now also requires
one of these in the changed lines:
- the token as a whole word inside a class, id, for, aria-controls, aria-labelledby or
  aria-describedby attribute value;
- the token after `.` or `#`;
- the token as a whole quoted string.

## Decided
- **Context, not a stoplist of common words:** a stoplist needs curating, and it would also drop
  a real `.note` change. Context keeps real uses and drops only prose.
- **A prototype bug, caught by measurement:** my first regex consumed the attribute's opening
  quote, so the first class in an attribute never matched (`class="pj-empty boardfail"` dropped
  render-project-members-3387). Lookarounds fixed it, and a test pins that case.
- **Weakest part:** a class added through something other than these forms (a template that
  builds the class name, `className = base + '-on'`) is not seen. That is under-selection, the
  same as before #4161, and it is the heuristic's known limit.
