## Change
\`usedAsSelector(token, text)\` in tools/bc-pr-select.js. The selector route also requires one of
these in the changed lines:
- the token whole inside a class, id, for or aria-* attribute value (with a left boundary, so
  data-id is not id);
- the token after \`.\` or \`#\`;
- the token whole inside a quoted string shaped like a class list: letters, digits, _, -, and
  spaces or tabs, never a newline; at most CLASS_LIST_MAX_WORDS = 5 words, where the page's
  longest class list is 4 (2567 lists of 1, 351 of 2, 37 of 3, 2 of 4).

## Decided
- **Context, not a stoplist of common words:** a stoplist needs curating, and it would also drop
  a real `.note` change. Context keeps real uses and drops only prose.
- **Two more limits found by re-measuring #4190 after widening rule 3:** \\s matched a newline,
  so a quote on one line paired with one lines later; and a quoted phrase in a comment ("you can
  still add the project") is class-list shaped. Spaces and tabs only, and the 5-word cap, fixed
  both.
- **A prototype bug, caught by measurement:** my first regex consumed the attribute's opening
  quote, so the first class in an attribute never matched (`class="pj-empty boardfail"` dropped
  render-project-members-3387). Lookarounds fixed it, and a test pins that case.
- **Weakest part:** a class added through a quoted string that also carries punctuation, or one
  built from fragments (`base + '-on'`), is not seen. That is under-selection, the
  same as before #4161, and it is the heuristic's known limit.
