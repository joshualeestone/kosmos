# tap-agent-4171: a notification tap opens the waiting agent on Android

Addresses #4171 (from Kano's #4140). Routed by Liu Kang (m1463, 2026-09-27).

## Finished means
After a notification tap the Android app opens the agent the notification was about, not the board
home: `https://<address>/?tab=detail&agent=<session>#kst=<token>`, the same deep link web push and
the iOS app use. A missing or invalid agent still opens the address (the board home). Proven end to
end on the AVD once Kano's relay side is testable.

## Contract (agreed with Kano before building, recorded on #4171)
The relay's sign-in page passes the agent as a string extra `agent` on the kosmos-open intent, next
to `address`, `addresses`, `kst` and `nonce`, only when the tap had one. The value is a session id
matching `^[a-z0-9][a-z0-9_-]{0,63}$` (web/sw.js `TAP_SESSION`, coordinator `tap_session`). Nonce
rules are unchanged: without the nonce it still opens in a Custom Tab, with the agent or without.

## Decisions
- **Validated again in the app** (`AddressChoice.AGENT_SESSION`), because the intent is exported
  and anything can send one. A bad agent is dropped, never a reason to refuse the address.
- **The query goes before the `#kst=` fragment**, so the board reads both.
- **Pinned to sw.js**: a test reads `TAP_SESSION` from web/sw.js and requires the same pattern, so
  the two cannot drift. The session cases mirror the iOS table case for case.

## Check
`AddressChoiceTest` (5 new tests) and `OpenAddressActivityTest` (2 new). Control: loosening the
rule to allow uppercase fails 2 tests (the sw.js pin and the bad-agent table).

On the AVD, end to end with Kano's relay at push-tap-4140 035edbd: the tap opened
`https://kano4140.kosmosplus.com/?tab=detail&agent=scorpion#kst=<token>`, and the no-agent control
opened the board home (`android/evidence/tap-agent-4171/`).

## Weakest part
The relay side it was proven against is unreviewed and may still change. The board did not load
(the Mac address does not resolve locally), so the proof is the URL, not the agent's page on screen.
