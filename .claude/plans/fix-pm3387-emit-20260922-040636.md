# fix-pm3387-emit -- make render-project-members-3387.js failures quotable

Branch: `fix-pm3387-emit`  ·  Repo: joshualeestone/kosmos  ·  Owner: Mona Lisa (night shift follow-up)

## What finished looks like
`docs/browser-checks/render-project-members-3387.js` prints each failing assertion on its own
`  FAIL  <msg>` line, so `tools/browser-checks.sh`'s `run_one` can grep the reason out of the
captured log and name the failing assertion, instead of the unquotable `console.log('problems:\n
...')` blob it shipped with (which surfaces only "(no FAIL or error line in its output)").

## Why (measured)
The check merged in #3387 (PR #3396) uses `console.log('problems:\n  ' + problems.join('\n  '))` on a
red. That line does not match the runner's reason pattern (`^\s*(FAIL|✖)|Error|Timeout|REFUS|refus`),
so a real red from this check would surface no reason. This was surfaced by the iteration-2 reviewer
on #3386, whose own new check was fixed to the quotable form at the time; this is the same one-line
fix for the sibling check that was already on main. Non-functional (the check still exits 1
correctly), so it is a diagnostics improvement, not a bug fix.

## Changes
1. `docs/browser-checks/render-project-members-3387.js`: replace the `console.log('problems:...')`
   blob with `for (const p of problems) console.error('  FAIL  ' + p)` (matching the quotable
   convention used by render-chatgpt-signin-no-name-2913, render-firstrun-grok-3386, etc.).
2. `browser-checks-reason-grep.test.js`: bump `EXPECTED_SITES` 122 -> 123 with a documented note,
   because the converted loop is now one recognized SHAPE-1 finding-emit site (the old blob was not
   counted -- a structurally-uncovered blind spot the test comments already name).

No web/index.html change, no product behavior change. Reversible.

  same defect + the exact fix, and the fleet had no unclaimed cards to pick up instead.
- Weakest premise: that a merged, non-functional diagnostics gap is worth a PR cycle. Mitigation: it
  is a one-line change to a check I authored two hours earlier; the alternative was idle.
- Reversible: yes.
