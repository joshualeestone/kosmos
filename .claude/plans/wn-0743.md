## Weakest premise
That the re-prompt happens on update. #5935 says it is expected and lists a real Developer ID build and upgrade as still
owed, so the line says "may". And setup.sh places the sealed app only when it wrote the account's install config; a
sandbox, a custom home, a failed config write or a tarball with no sealed app falls back to the old per-install bundle
(install.sealed-app-5896.test.js covers those), where nothing changes and no prompt comes.
