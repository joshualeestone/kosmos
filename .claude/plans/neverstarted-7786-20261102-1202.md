# neverstarted-7786: "Not started yet" for an agent that never took a turn

Card: #7786 (item 1 of 3). Owner: Baron Draxum.

## Problem
A launched agent whose self-report record holds only `started` rows reads "Idle"
(reconcileReport's last rule: `started` with nothing after it is IDLE), the word of
an agent resting after work. "Never started" and "started and gone quiet" look the same.

## Change
1. `selfreport.turnTakenOf(name)`: true / false / null from the append-only record.
   False only when the record exists and holds starts and stops only. No record or a
   record past the tail is null (no claim).
2. `status.neverTurnedOf(pane, status)`: the pane card's `neverTurned`, only on an
   idle card that is ours, only for Claude Code and Grok (both report prompts and
   finished answers through kosmos-report-hook.js). Paneless cards carry `false`.
3. `cardlabel.labelOf` and the page's `stateCopyOf`: "Not started yet", calm like
   Idle, after "Messages stuck". The phone gets the Mac's word ready-made (#7004).

## Rejected
- A new STATE (`not_started`): every consumer of state (counts, tone, Today, the
  phone's fallback) would need a branch; it is idle in every behaviour but the word.
- In-memory `lastWorked`: forgets across a board restart.
- All runners: Gemini, Codex, Antigravity and Muse turns may write no row, so a
  working agent would read as never started.

## Weakest premise
That every Claude Code / Grok turn writes a row. It rests on the hook wiring
(reporthook.js HOOK_EVENTS, groksettings.js); an agent whose hook is unwired writes
no `started` either, so it falls to null and keeps "Idle", the safe side.
A second gap, in the unsafe direction: the hook's report POST has a short timeout and
no retry, so a first turn taken entirely while the board was down or restarting
leaves no `working` or `idle` row, and that agent reads "Not started yet" until its
next turn. Rare (a board restart spanning a new agent's whole first turn), and it
corrects itself on the next prompt.

## Not in this slice
- Item 2 (a task whose owner never ran reads as owned): needs a task-row field and
  Tasks-view copy, so a design review; next slice.
- The other-computer agent list (web/index.html oaCard) reads STATE_COPY directly,
  not stateCopyOf, so it keeps "Idle" there, as it already does for "Messages stuck".
- Item 3 (why the reporter's two agents never started): no logs or version; not
  measurable from here.
