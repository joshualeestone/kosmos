Card #3244. Josh, #chaoskosmos-design 2026-09-17: he picked Option A ("iMessage Curved Wing") from
three tail options I posted for the message bubble. His complaints about the dialog boxes were the
avatar hanging below the bubble and a square NOTCH instead of a pointed/curved wing.

## Target
The PROJECT ROOM bubble `.msg-bd` (the `.msg` row = avatar + bubble, web/index.html ~4787-4823). The
agent DM thread `.dm` / `.dm-b` is a COLUMN with no avatar beside the bubble, so it has no tail and is

Enlarge the old small-notch tail into a soft curved flick, on the SAME two-shape mask the code already
uses (`::before` = `background-color: inherit` colored wing; `::after` = `--k-bg` ground mask carving

- ::before 12x17, elliptical bottom radius 16px 15px.

## Load-bearing invariant (do NOT break)
The wing stays ENTIRELY OUTSIDE the bubble box (left/right:-W; width:W; inner edge flush AT the edge),
because `--usermsg-tint` is TRANSLUCENT: a wing overlapping the painted body double-composites into the
"colliding triangle" Josh rejected (#3130 / 6.72). The mockup's original Option A geometry OVERLAPS the
box, so it was NOT pasted; V1 rebuilds the curve on the no-overlap mask. The wing is absolutely
positioned + bottom-anchored, so the taller size adds NO row height (no reflow; render-room-scroll.js
is the scroll-repin oracle, #1147/#3200).
