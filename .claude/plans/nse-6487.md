# nse-6487: the iPhone shows a notification as a message from the agent (kosmos#6487)

Josh, 2026-10-22 13:28: "use the agent avatar and put the actual text, like discord does".

## Finished looks like
A notification from an agent shows, on Josh's iPhone, the agent's name, its picture and what it actually said, fetched
from the person's own computer. The words never ride the push. When the computer does not answer, the notice shows as
it does today.

## The change
- A Notification Service Extension, `KosmosNotice` (`io.kosmos.app.notice`), embedded in the app. On a push it asks the
  computer the push names (`address`), with the session the app keeps for it, for `GET /api/phone/notice?id=<id>`
  (board branch notice-6487), and shows the words, with the picture as an attachment.
- The app keeps that computer session in a keychain group the two share (`<team>.io.kosmos.app.shared`), moved there
  add-first; the app's other items stay in its own group.
- `archive.sh` signs each target with its own profile (`KOSMOS_IOS_NOTICE_PROFILE`) and passes the bundle id as
  `KOSMOS_BUNDLE_ID`; `check-ipa-entitlements.sh` checks the extension.

## Apple side (done with the team's App Store Connect key)
App ID `io.kosmos.app.notice` (8UFP5JXR28), profile "Kosmos Notice App Store" (9GNVLGBJ53), installed on Agent1s.
Communication Notifications (the chat-style look) cannot be turned on by the API: it waits on Josh in the developer
portal, so `KosmosMessageStyle` is false and the picture rides as an attachment.

## Order
Independent of the board and relay branches: without them the extension gets no answer and the notice shows as today.

## Weakest premise
The keychain move and the extension's runtime have never run on a phone; LogicTests cover the UIKit-free logic only.
