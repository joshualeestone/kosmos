# reload-button-995: the footer offers the control that matches the state (kosmos#995)

## Why

Josh, 2026-08-26 11:26, with a screenshot:

> *"if we could put a 'reload' button so it would be like 'Reload' to update to Beta Version
> 0.5.66. Right now it tells me twice to reload but the only button is Check For Update. If we
> know there is an update available we dont need the 'Check for Update'."*

He is right and the cause is positional: `putBtn('Check for Update')` sat OUTSIDE the branch
that knows the page is stale, so the one state where Kosmos has already determined the answer
offered the one control whose job is to go and ask it.

## What

In `paintUpdateCard`'s reached-and-readable arm, the button branches on `pageIsStale(running)`:
`Reload` / act `reload`, else `Check for Update` / act `check`. The click handler gains a
`reload` arm that calls `location.reload()` with no confirm, because nothing is installed and
nothing is irreversible.

⚠️ **The button is deliberately NOT gated on `UPD_ASKED` while the sentence still is**, and that
asymmetry is the fix rather than an oversight. The `UPD_ASKED` gate exists because a VERDICT
answers a question, and until somebody asks there is none. A CONTROL is not a verdict: offering
the right button claims nothing. **And Josh's case is precisely the ungated one** — he never
pressed Check; the news reached him from the build line above, which announces staleness
unasked. A button gated on `UPD_ASKED` would leave his screenshot unchanged, which is why the
never-pressed-Check case is the first assertion in the test.

## 🛑 The second half of #995 is NOT in this branch, and my claim on that card was wrong

The card also says the engine-stale notice should stop telling a person to type
`kosmos restart` into a terminal, and I wrote that #985 made this fixable because "the app can
already restart the board by itself".

**That is true of the NATIVE APP and not of the page, which is where that notice lives.**
Checked, both halves:

- there is **no board-restart route** — `kosmos restart` appears exactly once in the whole repo,
  as the text of that very sentence;
- the page **cannot tell it is running inside the native app** — no custom user-agent, no
  injected flag, nothing.

So the notice cannot honestly become a button, and it cannot even say "press ⌘R" without
knowing the reader is in the app. Making it fixable is a real change (a signal from the app, or
a restart route), not a copy edit. **Recorded on the card as a correction rather than silently
dropped**, because a card that says a thing is nearly done is worse than one that says it is not
started.
