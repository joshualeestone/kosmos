# v2look2-5551: the project header's settings cog as a round button (kosmos#5551, slice 2)

Stacked on v2look-5551 (#5579, squash-merges on green); rebased onto main after it lands.

## Finished means
With the new look on (outside the consolidated layout), the project page's settings cog is the same round 40px
button as the Back button beside the name: same size, round, same hairline edge. With the look off, the cog is
today's 28px icon. render-newlook-4470.js asserts both, at 1280 light/dark and 390 light.

## Context
The v9 drawing (Files: kosmos-project-two-col-v9.png) draws Back, search and settings as matching round buttons.
The look already drew Back round (#4470); the cog was still today's bare 28px icon.

## Decided
- CSS only, new look only, one rule beside the existing Back rule; the cog copies Back's declarations.
- The edge is kept, as Back keeps it: in this look a plain button on the white page keeps its edge (the create-flow
  note). The drawing shows a grey fill with no edge; matching Back beats matching the drawing, so the pair agrees.
- Rejected: the drawing's search ICON. Today search is a field you type into; an icon that opens a field is a
  behaviour change (Angel's lane), and fields keep their edge in the look. The field is unchanged.
- Rejected: a pill-shaped search field. The drawing has no field to copy, so the shape would be invented.
- Weakest premise: phone width. At 390px the 40px cog takes about 12px more from the project name, which already
  truncates ("Lau..."). Kept, so Back and the cog stay a matching pair; a phone-only 28px cog is the fallback if
  Josh finds the name too short.
