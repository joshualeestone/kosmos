# newlook-dleft-4470: an agent's page in the new look, slice 2 (the left column), behind the switch

Card: kosmos#4470 (page order: project page, Agents, Tasks, an agent's page, Settings, phone). Follows slice 1
(#4870, the conversation).

Finished looks like: with the new look on, an agent's left column reads like the project page's left column in Josh's
v9 drawing and the built project page: one grey box (#f5f5f7 / #2c2c2e, 28px corners) holding the name block, the
section buttons and Files; at a desktop width (68rem and up) the column is the project page's 300 to 380px, so file
names show whole; the section buttons lie flat on the box with no edge and no gold, the open one a tile in the page's
ground with its label in full ink (a shape cue as well as a colour one); Files has no card, a hairline above it and the
project page's sentence-case grey heading. With the look off, nothing changes.

How it was decided: rendered first (mobile-shots agent-chat / nl-agent-chat / nl-agent-profile, desktop and phone,
light and dark). With the look on, the column was still today's: a gold-washed open tile with a gold edge, edged tiles,
a white Files card with spaced capitals and cut-off names. There is no drawing of the agent page itself, so nothing new
is drawn: the project page's already-approved left-column rules (.pjsplit box, .dlab heading) are applied to this column.

Rejected:
- Keeping a gold cue on the open button: the new look's tabs carry "current" by ink and weight, never gold (card rule:
  "active nav tab = just black, same weight").
- Restyling the swarm button: it carries its state as a tint plus a worded pill (#4433, WCAG 1.4.1), so it keeps both.
- The "All agents" back link and the name block: the header is its own slice, as the project page's round back button
  was.

Weakest premise: that the open button should be a page-ground tile (a segmented-control look) rather than only darker
ink. Ink alone would match the top tabs exactly, but on a 3-up button group with icons the tile reads at a glance and
does not depend on colour.

Validation: render-newlook-4470 gains DLEFT_LOOK (on light/dark/390, chosen Dark, and the off control equal to the
before-switch reading with today's gold edge and FILES capitals pinned). Negative control: without the CSS block every
on arm fails (12 FAIL, 192/204), the off controls still pass. Look-off screenshots differ from before only in the two
animated working-dot rows and a relative time ("57" vs "56 minutes ago").
