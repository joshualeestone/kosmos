# kosmos#8378 cluster 3, slice 1 (branch wincl3-8378)

Cluster 3 is 62 test files that fail on GitHub's Windows runner (Mona Lisa's how-to comment on #8378, comment
7235170746; the list is comment 7235171228). This slice takes the files whose failing arms test something Windows
does not have, plus three small fixes found on the way. The rest of the cluster is the next slices.

## Measured first

Run 46116045018 and 46116329603 on the never-merged branch `wincl3-8378-never-merge` (GitHub's windows-latest, the
way tools/windows-tests.js runs a file) gave every failing test name and its error, not just the first one.

## What this slice does

- **Skips, each naming its mechanism** through `skipOnWin32(reason)`, with the matching HOST_BRANCH_EXCLUDED entry
  in tools/windows-tests.js carrying the same reason (engine/windows-tests-1777.test.js checks both):
  - 11 `supervisor.*` files: they run bin/agent-supervisor.sh through /bin/bash with a #!/bin/bash fake tmux. A
    Windows agent runs under its own per-turn supervisor.
  - engine/tmuxsignin, engine/status.tmux-bin, engine/status.snapshotunheld-7693, install.tmux-pick: /bin/echo,
    /bin/sh and shebang fake tmux. Kosmos runs no tmux on Windows.
  - 15 `install.*` files: they drive install/setup.sh (it stops on any system but macOS and Linux), the .pkg
    postinstall, or run-setup, through a POSIX shell. Windows installs and updates from its own package.
  - The chmod and file-mode arms of 11 engine and root files (skills, streak, replynudge, usage-cursor,
    personalbackupkey, taskchat, setup-assistant-3034, usage-installday, projects, reporthook, trust).
- **Fixes, not skips:**
  - engine/worlds.registry-1704: asked `dataRootFor('darwin', ...)` with a Windows temp path, which the darwin joiner
    calls relative. It now asks for the host's own platform; the darwin-pinned comparison above it is untouched.
  - install.sharedicon-5913: every test already skips off a Mac, but the file called `process.getuid()` at load,
    which Windows lacks, so the file failed before any skip applied.

## Decided, and what I rejected

- Skip each failing ARM, not the whole file: arms that pass on Windows keep running there.
- Rejected: rewriting the supervisor and installer tests to run under Git Bash. The scripts under test stop on, or
  are never shipped to, Windows, so a Windows run would test nothing a Windows user gets.

## Weakest premise

That `setup.sh` and `run-setup` are never reached on Windows. Measured from source: setup.sh exits on any `uname -s`
but Darwin or Linux (line 99), and run-setup fetches the arm64 or linux-x64 manifest only. If a Windows path ever
calls run-setup, the setup-sig-6468 skip would hide it.

## Checked

- Every edited file passes on the Mac (`node --test`), with engine/windows-tests-1777.test.js green.
- The Windows rerun of all 62 files after this slice is the control that the skipped arms now skip.
