# s7c-6587: the Kosmos+ service key warning outside Settings (S-7a slice 2b)

Card: kosmos#6587 (detail private). Stacked on s7b-6587 (slice 2a: the engine state, /api/remote serviceKeys, and the Settings line #plus-sk-line), itself on s7a-6587 (the verifier, PR #6672).

## Finished looks like
With a mismatch, a person on any view but Kosmos+ sees one fixed warning card in the floating stack, right after the certificate notice. Review opens Kosmos+ with keyboard focus on the pane's line; Close puts it away for this browser session. Every other state raises nothing. As shipped (state off) nobody sees anything.

## Decided
- **The certificate notice's pattern and look** (#6613: `utoast cwnote`, role=status on the words, Review and Close, hidden on Kosmos+, repainted by syncPlusChrome when Kosmos+ opens or closes, carried on pollCwNote's /api/remote answer). Rejected: a second poll (one answer serves both).
- **Put away for this tab, and only for the mismatch the person saw.** The server passes only a state, so there is no finding key like #6613's. Close or Review sets a sessionStorage flag (per tab, surviving a reload; the tab's own memory when storage is blocked), and any real answer that is not a mismatch clears it, so a later mismatch in the same long-lived tab is raised again (review 1; the first version kept it put away for the whole tab). An older board's answer (no state) does not clear it. Kosmos+'s own line is never put away. Weakest premise: a person who closes it sees it again in each new tab while the mismatch lasts; it is a security warning that should be rare, so repetition is the safer side.
- **Review puts it away at once**, unlike #6613, which waits until the pane says the finding: the pane's line is painted from the same answer and says it while the mismatch lasts. Focus lands on the line only when #plus-flow is shown (a pane that did not paint keeps an old line in a hidden container), else the heading (review 1). Weakest premise: a pane that fails to paint costs the person the notice for this tab until the next non-mismatch answer.
- **An older board's answer (no serviceKeys)** leaves the notice as it is, as the line does.
