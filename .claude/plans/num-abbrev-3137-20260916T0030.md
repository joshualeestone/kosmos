# Plan: abbreviate large numbers in the Token Usage stat tiles (#3137)

Josh 6.68 (screenshot): the fixed-width Token Usage stat tiles CLIP a full thousands dollar
figure. "$176,332" (Approximate Human Cost) ran past the tile edge (overflow:hidden). Abbreviate
large numbers in the tiles (e.g. $176,332 -> $176K) so they fit.

## Done-condition
- The Approximate Human Cost tile shows an abbreviated $NK (not full digits) for thousands values.
- The Equivalent Token API Cost tile abbreviates the same way.
- No hero stat tile clips its figure (every .tv-fig fits its box).
- The per-row table Value column is UNCHANGED (still the exact #2840 figure).

## Approach (chosen)
- New `usageUsdTileSub1M(n)`: tiles' sub-$1M range -> `$NK` (v/1e3, toFixed(0), no decimal per
  Josh's "176k"); below $1k keeps the exact $N/$N.NN.
- `usageHeroHtml` valueStr + apiStr use it for the sub-$1M range; the >=1e6 bands stay as-is
  (hero $X.XM one-decimal, API cost usageUsd $XM whole -- the approved mock's intentional diff).
- `usageUsd` DELIBERATELY untouched -> the per-row table Value stays exact (#2840 ruled the table
  shows the exact figure, and the column has room; Josh only reported the fixed-width TILE overflow).

## Rejected
- Change usageUsd globally: would abbreviate the table Value too, overriding #2840 for a surface
  Josh did not report as broken. Rejected.
- Width-threshold abbreviation (only >= $100K): second-guesses Josh's literal "when in the thousands,
  abbreviate" rule; more complex. Rejected in favor of his stated rule.

## Weakest premise
Small thousands round in the tile (e.g. $1,152 -> $1K, ~13% under-report). Accepted per Josh's
literal rule + his no-decimal example, and because the tile is a compact headline (the exact figure
lives in the table). If Josh wants small values kept exact or a decimal ($1.2K), it is a one-line
change (a threshold or toFixed(1)). FLAG to Josh.
