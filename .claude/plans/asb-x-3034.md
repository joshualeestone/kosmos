# asb-x-3034: opened, nothing typed, then X asks how to close it for good

Addresses #3034 (Josh 2026-09-25 07:38, #admin, verbatim): "If somebody clicks on the assistant
agent and doesn't type anything and then hits the X, we should show them the message to dismiss it
permanently (because that's probably what they're trying to look for at that point)".
Handed over by Mona Lisa (she is on #1307).

## Before
asbX asked "Close the assistant?" only the first time (setting.asked !== true); after that, X just
closed, however the chat had been used.

## Change (web/index.html)
- ASB.sentThisOpen: reset by asbOpen, set by asbSend on any non-empty send attempt.
- asbX asks when the choice was never answered (as before) OR when this opening did nothing:
  nothing sent AND the box unchanged since it opened (ASB.draftAtOpen, recorded by asbOpen).
  Otherwise X just closes, as before.
- asbStepping still wins: when the assistant is going anyway there is nothing to ask.

## Decided
- "Doesn't type anything" is read as nothing sent and nothing typed: a question written and not
  sent is using the chat, not looking for the way out. Weakest premise: Josh may have meant "sent".
- An attempt to send counts even if the answer fails.
