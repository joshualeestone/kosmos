# reachposix-5548: engine.reachable holds on Windows, and its guard can see an orphan there

Addresses #5548 (item 3 of #6113). Liu Kang's ruling m5395.

## Finished means
- engine.reachable.test.js passes on the windows CI job with its test count, and the job's line is quoted in the PR.
- On Windows the main orphan guard can still find an orphan (not passing because every module looked like its own caller).
- The windows job keeps running the file (ALSO_ROOT).

## Measured cause (draft #6153, run 38565268662; written up on #5548)
findOrphans skips a module's own file with `s2.f !== rel`. rel is posix; the caller keys were path.join, so on
Windows `engine\x.js` never equalled `engine/x.js`. Every module counted as its own caller: all 31 TRIAGED_5548 names
"gained a caller", and the main guard could find no orphan at all.

## Change (sweep of every path key in the file)
- CALLER_FILES: every key posix (engine, web, install, tools, test-support, bin).
- testFiles: posix keys, for consistency (only read, never compared).
- engineModules: already posix rel (review 2); its read now takes the posix key too.
- The two bin/ regexes (comment strip, the agent-supervisor fixture) narrowed from [\/\\] to posix.
- Not changed, checked: TRIAGED_5548, SEAMS_5548 and NO_LITERAL_EXPORTS hold posix literals compared with posix rel;
  every path.join left joins __dirname for a read or stat, where Windows takes a forward slash.
- New test: every engine module's rel is a caller key, and no key holds a backslash (fails on Windows before the fix).
- New self-test case: the module's own file in the caller list must not hide an orphan (fails if the skip breaks).
- tools/windows-tests.js: engine.reachable.test.js in ALSO_ROOT.

## Decisions
- Posix keys rather than normalising at the comparison: one place (the key) instead of every compare.
- Weakest part: the Mac controls fake Windows by joining relative paths with path.win32.join; the windows job is the
  real check, and the PR quotes it before merge.
- Would change my mind: the windows job failing on anything else in the file.
