# createpage-tabs-3495: Create/Join tabs + Kosmos+ gated external-add modal (#3495)

## Goal (Josh, 2026-09-23, design channel, with target screenshots)
Rework the project-creation / external-project view:
1. Remove the top explainer paragraph ("Working across organizations is a Kosmos Plus feature...").
2. A two-option tab/segmented selector at the top: "Create a project" and "Join an external project"
   (exactly those two).
3. "Join an external project" is Kosmos+ gated: clicking it shows "It's a Kosmos Plus feature and you
   must be logged in to access it."
4. "Create a project" keeps the grayed "Add an external person" / "Add an external agent" buttons.
   Clicking a grayed one makes it clickable and shows "To connect external people or agents, you must
   be signed in as a Kosmos Plus user."
5. One shared pop-up modal serves both prompts.
Gating is display-only (prompts, no real auth enforcement). Target: 0.6.90 fast-follow.

## Co-land (two halves, both on this branch)
- **Design half (Mona Lisa, 354da276):** the shared `#plus-gate-modal` (.rm-back/.rm-box) + a
  `showPlusGate(kind)` function carrying the two VERBATIM copies (join/connect); relabelled the toggle
  to "Create a project" / "Join an external project", restyled it segmented, removed the top explainer.
  Josh's copy is verbatim.
- **Gate-behaviour half (Angel, c5e95167):** dropped `.pj-mode` + the two `#pj-add-ext-*` buttons from
  the `data-fed-ui` display:none rule, so the toggle + Add-external buttons ALWAYS show (grayed but
  clickable) for non-"show" viewers; only the Plus-only content (`#pj-invite-panel` + `#pj-join-mode`)
  stays display-gated. `fedShow()` reads the same `data-fed-ui` stamp the CSS reads (fail-safe false
  pre-first-tick). A non-"show" viewer selecting Join -> `showPlusGate('join')` + the toggle snaps back
  to Create; clicking a grayed Add-external button -> `showPlusGate('connect')` instead of minting.
  The decision is Angel's, the modal is Mona's (one shared API, no duplicated logic).
