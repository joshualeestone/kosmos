# noise2-6533: five repeated lines removed (kosmos#6533, #6535 to #6538; #6534 withdrawn)

Part of the 0.7.57 board noise read (Josh: keep the interface clean). Removals and merges only; no new control
and no new wording beyond what a merge needs. Cards were read from source; owners agreed these are built here.

## Per card

- **#6533 update overlay (did not take / failed / slow).** Removed the "Reload and try again" button: it ran the same
  `location.reload()` as "Reload". Kept the gold Reload (its label says what happens); the reloaded page offers
  Update again from its own chip. In did-not-take, "Kosmos came back on the same version." goes: "Kosmos is still on
  X." follows it. The old no-version fallback SENTENCE went too (review 1), but the no-version branch stays: with no
  version the overlay stops at the bold line (plus any installer notes) and never names an empty version, defended
  by its own test.
- **#6534 update notices: WITHDRAWN in review 1, not built.** The update-abort marker stays until an update gets
  past the pause (engine/update.js), and with auto-update off the chip's Update button is the board's only Update
  door (maybeAutoInstall retries only when auto is on). Hiding the chip while the abort notice shows would leave only
  the route in Settings, so the chip is not noise. The page, its paint order and render-update-abort-2055 are as on
  main; the card is closed as not planned.
- **#6535 restart notice failure states.** The small lines no longer open with the bold line's words: "It keeps
  running the old copy until it is next started." and "Try again in a moment." (twice). The bold lines stay; they
  carry the news at every width (the small line is hidden under 720px).
- **#6536 restart notice.** Dropped "A restart picks it up."; the title and the Restart Kosmos button say it. The
  phone's "Restart it from Kosmos on that computer to pick it up." stays (no button there). The cannot-restart
  variant is merged rather than cut: "Kosmos cannot restart itself here, so the change takes effect when it is next
  started." replaces "so it keeps running the old copy until it is next started", which repeated the "still running
  the old copy" the line before it already says.
- **#6537 offline.** OFFLINE_SENTENCE is now only "The board tries again by itself when you are online again.", and
  the agents card lost its bold "You are offline.". The top note keeps "You are offline" and the not-connected
  sentence. Every path that sets BOARD_DEVICE_OFFLINE true paints it in the same branch: the status poll's catch and
  (review 1) loadProjects' catch, so a phone that goes offline and opens Projects before the next status poll still
  gets the note. The projects path paints the offline note when it finds the device offline and takes it down when
  it finds the device online (review 5: one rule, offlineNoteDown, for a readable read and a failed one with the
  device online; a "not answering" note is never cleared from there). So the note goes up with the shortened lines;
  the one gap, new with this change and accepted because the device is online then, is that the agents card may show its shortened text for up to one status poll
  after a projects read clears the note. Under 720px the note's small line is hidden (.utoast .utxt small), so on a phone only the bold
  "You are offline" shows and the not-connected sentence is not on screen. Accepted: the bold line carries the fact.
- **#6538 not answering.** Dropped "Something on this computer did not answer, so we are not telling you the board
  is empty." The card keeps its bold line, "This is not the same as having none.", the reason and Try again. The
  top note names which machine did not answer when nothing answered (a refusal from the board shows no note, and
  the card then names no machine; accepted, the removed sentence was loose there too).

## Weakest premise

#6537: the projects path paints the note only for the offline case; a projects read that got no answer while the
device is online leaves "not answering" to the status poll, which owns it. If that gap shows on a phone, widen it.
