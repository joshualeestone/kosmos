# cancel44-7117: Cancel's 44 pt target inside the button (#7117, follow-up to #7089 and #7096)

## Finished looks like
On main, both search rows' Cancel buttons (ChatView, RoomView) carry their 44 pt frame and a rectangular content
shape inside the Button's label, so the tap area is at least 44 by 44 pt; the row looks the same.

## Build
Replace `Button("Cancel") { ... }.frame(minHeight: 44)` with a label holding the Text, fixedSize, the frame and
contentShape, and `.buttonStyle(.plain)` as the x beside it has.

## Decided, not missed
- `.buttonStyle(.plain)` matches the x beside it, including its press feedback. The colour comes from the
  Text's own foregroundColor(Palette.primary), which wins under any style, so keep that on the Text.
- Visual check by screenshot; the tap area itself is a device check (no UI test harness here).
