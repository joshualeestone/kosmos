## Decided
- The fix is rank 8, outside the window. It closes a real hazard but only for adopted sessions in Claude's default
  mode and for protected-folder prompts; launched agents never reach a permission prompt (bypass mode plus the
  allow hook since 0.7.28), so most people never meet it. A narrow fix should not push a feature out of the five.
- #5746 (a reply by number reaches Claude's question menu as the answer, not the highlighted default) is the one other
  user-facing change merged since 0.7.36 froze (b2e12109350d); it is rank 7.5, also outside the five: a fix to how a
  reply lands, smaller than any of the five. The rest since the freeze is invisible to people (#5434 fsync slices,
  #5727 test migrations, #5643 `kosmos task ran` retry). 0.7.37's versions-page entry names the permission fix.
- ORDER: #5760 is not merged yet. The 0.7.37 cut requires BOTH #5760's merge sha and this PR's on main (the waiter
  passes both to the cut, which aborts unless each is an ancestor of the frozen tree), so the pool's `since` 0.7.37 is
  true of the build that ships it.
- Distinct ranks (7.5, 8.5) so no tie-break decides the order (ties go to the newer version).
