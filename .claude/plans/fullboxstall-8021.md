# fullboxstall-8021: a box that stays full is a stall
Card #8021. On a throwaway board a seat that ignored Enter stayed full for 63 minutes with no stall line. Traced: the first send is `busy` and skipped by `note()`, and every later one is kept by messages.js before any delivery verdict, so nothing counted. A person away from the board heard nothing: a card sentence and a log line.
**Call:** each stuck-input pass, for a card whose box has stayed full with anything kept for it (a limit that has ended included; the box is what stops it now), notes one `{state:'could_not', inputHeld:true, swept:true}`, counted apart from real tries in `swept`. So the existing stall line, push and end apply, with no new path, and the log claims no tries that were not made. Once the box stops reading text or nothing is kept, the sweep takes back only its own passes: real failures stay. A stall already said keeps its date, and still ends when its message lands.
**Rejected:** dropping `busy` in `note()` (it would not reach the messages.js holds, and it was added for a reason). A new push kind (a second path for one fact). `reset` on take-back (round 1's first try: a review measured it wiping real failures).
**Accepted:** with a limit shown and the box also full, the stall names the box, which is true but not the whole story. A said stall whose messages drain with no line landing has no end line, as the existing rule is that only a landed line writes one. An unreadable queue file reads as still kept, so a pass can count with nothing kept: rare, and it clears when the file reads. `lastAt` stays at the last pass after a take-back, so a real stall stays fresh a little longer.
**Weakest premise:** that the real box state resembles the fake seat's; the cause of a real box that ignores Enter is unknown. A person typing slowly with messages kept for 30 minutes also gets a stall line, which is true: they are not reaching it.
**Deferred from review, with why:** a box that fills again while its messages still have not landed resumes the old stall under its old date. The line says "no message has been seen to reach it since" that date, which is true, and the existing 24-hour rule stops a second line and push. A said stall whose messages age out ends with no line: the only end line says a message was placed, which would be false, and the card clears.
