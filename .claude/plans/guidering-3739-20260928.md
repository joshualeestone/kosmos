# #3739: the guide's page draws an empty memory ring before its first session

## Why
Josh (0.6.94): the setup guide "renders with no context ring, and a model that says Unknown". #3761 fixed the title,
the hiding and "Unknown", and named the ring as not done: the guide's own page draws its avatar with no ring before
a reading. The fresh-install check on served 0.7.06 (this card, 2026-09-28) confirmed the rest holds.

## Change
- `detailRing` (web/index.html): with no reading, the guide (`isGuide`) gets the empty track; any other agent still
  gets nothing (#1915: unknown draws no ring; the MEMORY box says why). With a reading, the guide's ring is the
  ordinary filled one.

## Decided
- Guide only, not every agent: Josh's note was about the guide, which is shown before it has ever run; for other
  agents "no reading" can mean stopped or unreadable, and #1915/#3501 chose to draw nothing then.
- Rejected: starting the guide's session at first launch to get a reading (the card's other option). It spends
  the person's model before they asked anything, and the ring would still be empty.
- Weakest premise: an empty track could read as "0% used". For a guide that has never run, that is true.

## Tests
- web.guide-ring-3739.test.js: guide with no reading gets the track and no fill; controls: an ordinary agent with
  no reading, or an unreadable percent, gets nothing; with a reading the guide matches an ordinary agent. Red with
  the change reverted.
- render-guide-hidden-3739 (browser check, already wired): the guide's page draws the empty ring; CONTROL arms: the
  guide has no reading, and an ordinary agent with no reading draws no ring. Red with the change reverted.
