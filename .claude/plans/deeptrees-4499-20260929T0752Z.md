## What changed (web/index.html, orgPlace)
1. **Wide window first.** Each team first tries ORG_WIDE (0.95) quarter-turns either side of its manager, or ORG_WIDE_FIRST (1.45) for a first-ring manager, with no tangent cap. It is kept only if:
   - no new line crosses any line already drawn (exact test, as web.org-sectors-4434 counts a crossing);
   - no report line comes within ORG_HUB_CLEAR (74px) of the hub;
   - faces are ORG_MIN_ARC apart;
   - every line clears every face by ORG_LINE_CLEAR both ways.

   Otherwise the team takes #4472's capped placement.
2. **Shares in a wide window** are leaf count to ORG_SHARE_POWER (0.85): measured best of 0.4 to 1.0.
3. **Line bands** start at each line's true nearest approach to the hub, since a wide line can dip inside both its ends. A first version skipped such a line and let one pass 0.6px from a face.
4. **Per-team filter:** only faces and lines whose angle reaches the manager's slice (plus the spacing and clearance) are checked. For 1000 agents this took the time from 84ms to about 21ms.
5. **First ring:** a spilled agent takes the free angle nearest its slice centre, from blocked intervals (same-lane spacing, and 12px from every other face's hub-line crossing, both ways). If any agent still cannot clear, the first ring starts further out, at a base found by bisection. That base always clears: `hi` only ever holds a base that cleared, or `settledBase` (1px past the point where neighbouring slice centres are ORG_MIN_ARC apart and everyone fits the first lane).
6. **The exact crossing test also runs on capped placements.** Across the 7,319 trees it never fires there. Without it, randomTree(3, 200, 0.01) has 2 crossings under the wide window.
