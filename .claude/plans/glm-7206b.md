# glm-7206b: #7206 slice 2b, Z.ai GLM on the page

Slice 2a (PR #8089, main 93c35c6760) built GLM in the engine and held it off with `pageReady: false` until the page
knew it. This slice is the page, and it removes that hold.

## What
1. `web/index.html`, the key form (`acct-compat-flow`): one form for every vendor whose endpoint speaks Claude Code's
   API, painted per vendor by `acctCompatShow(vendor)` from `COMPAT_PAGE` (name, key label, placeholder, key page).
   DeepSeek's words stay the markup's own; GLM's form asks for a GLM Coding Plan key by name and says a pay-as-you-go
   key may be refused (checklist item 4 on the card: the check reads the Coding Plan list).
2. One switch per vendor on the page too: `compatAsk` fills `COMPAT_ON_FOR` from the board's own list of the vendors
   whose switch is on. `COMPAT_ON` is "any". Every menu row, the Add a provider pick, the create and switch menus
   (`paintKeyedProviderOptions`) and the setup step's rows (`frPaintCompat`) read the vendor's own answer.
   A definite off for the OPEN form's vendor puts it away; an off for another vendor, or a failed ask, never does.
3. GLM beside DeepSeek at every page site that names a vendor: `ACCT_KEYED_ROUTE` (glm -> compat), the words
   (`switchKeyedWord`, the overview, the project tally, the model line, "the account names the model", the auth
   failure sentence), `providerOf`, the switch dialog's account, `switchCrossesFamily` (a vendor keeps its sessions
   in its own folder), the provider mark.
4. `engine/accountmove.js` moveChatWord: glm -> "Z.ai GLM".
5. `engine/anthropiccompat.js`: the `pageReady` hold and its test-only `AGENT_WORKFORCE_TEST_COMPAT_READY` override
   are removed. GLM is on exactly when `compat-glm-on` exists. No board has that marker.

## Tests
- `docs/browser-checks/render-glm-add-7206.js` (new, gated): the per-vendor switch end to end in a browser. Red
  against a mutant that reads one answer for every vendor (5 failures).
- `server.compat-hidden-7206.test.js`: compatAsk per vendor, Windows, failed ask, off for another vendor.
- The 2a readiness tests become "on exactly when its own switch is".

## Not here
- The switch-on checklist (on the card): a real Coding Plan key, the model list's spelling, a real claude run, a
  pay-as-you-go key. Nobody creates `compat-glm-on` before that.
- Slice 3, MiniMax.
