## The item
- title: "The restart note says when restarts repeat"
- line: "When this computer has restarted at least 3 times in a week while Kosmos was running, the restart note says

- icon shield, rank 11.35, since 0.8.15, status pending, no platform tag.

## Decided
- Rank 11.35, just after the last of 0.8.15's five ("A new Cloud machine can be allowed", 11.3, in PR #8891's pool).
  The build takes the top five pending items by rank and never filters by `since`, so a rank above any of those five
  would enter 0.8.15's own window if this merged before the cut froze main, and the cut's check would stop on a window
  that no longer matches the pool (round 2 WARNING, measured on #8891's pool: 10.46 pushed 11.3 out). At 11.35 it is
  sixth, so it cannot change 0.8.15's window whenever it merges. Rejected: 10.46 beside the restart-note item (the
  above), and relying on merge timing alone. It still waits for the 0.8.15 cut's hold to lift, like any merge.
- No platform tag: engine/restartnote.js makes the note on every platform (no platform check in atStart), and the page
  shows it wherever the note exists. The neighbouring item is tagged mac; that tag is about its own checks, not this
  line. Weakest premise: if the note is in practice never made on Windows (its start-up passes nothing about who started
  the board), Windows users would read a line about a note they rarely see. It is still true when it is made.
- "this computer" as the rest of the pool writes it; a cloud machine's page rewords the note itself, not this list.
- Not the cloud wording: one line per highlight, and the cloud ending is a detail of the note.
