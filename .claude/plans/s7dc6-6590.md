# s7dc6-6590: the board writes the board-v2 marker (kosmos#6590, S-7d branch c, part c6)

Stacked on s7dc4-6590. The design is private (kosmos-relay `.claude/plans/s7dc-6590.md`).

## Scope
engine/remote.js `writeBoardV2IfReady`, run from ensure() on every tick: writes `<state>/board-v2` (owner-only, whole,
by rename) when Kosmos+ is on, the computer is enrolled, no register or Forget is running, and the running connector
lists `device-proof-v2`. Never removed by the board. `KOSMOS_BOARD_V2=0` holds the write back.

## The cost, in plain words (for the card and the release note)
Once a computer has the marker, its tunnel starts enforcing within a few hours. From then on a new phone or browser is
let in only by typing, at that computer, the code its own page shows. Every phone and browser let in before must be let
in again that way within 7 days (its old sign-in keeps working until then). Someone away from their computer for longer
than that cannot reconnect until they are back. A board rolled back after this leaves the marker and admits no new
browser (it fails closed); only the tunnel's own off switch (KOSMOS_GATE_DEVICE_PROOF=off) undoes enforcement.
