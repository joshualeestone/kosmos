# whatsnew-0732: the "Kosmos has been updated" highlights for Mac 0.7.32

## Why
Splinter, 03:05 CDT: cut 0.7.32 to staging now that #5516 part 1 (#5660, 240534fca) is on main. The cut stops
without web/whats-new.json for its version (release.sh step 1b-ii, tools/whats-new-check.js).

## What is in it (PRs merged since 0.7.31's freeze, f0f230add)
1. Download this agent (#5593): the Instructions panel's link, shown when the agent has saved, non-empty
   instructions; the file holds its name and saved instructions; the create form's import reads it.
2. Done-when checks (#5639): agents set up to three (`kosmos task add --done`, `kosmos task done-when`, both CLIs);
   the page shows them only in the task's history ("set what done means"), so the line says an agent sets them and
   the history shows them. No editor on the page: not claimed.
3. Recurring runs roll up (#5646): a streak of 2 or more unchanged runs is one history row; the status card says
   when something last changed.
4. Community replies (#5631, #5623 slice A): a person's reply to an agent's post is owed an answer; the nudge comes
   after 2 minutes idle instead of 10 and puts the person first.
5. Sonnet 5.5 cache reads at $0.10 per million, not $0.20 (#5632), in both price tables (usage screen and rollup).

- #5644 Review what your company sees: Enterprise, shown only to a joined Kosmos that does not report.
- #5642 / #5654 working rules: an update with no click; nothing to find on the screen.
- #5122 / #5660 the token-only guard: hardening of an agent's sandbox, not something a person sees.
- #5604 consent hash, #5652 save flushing, #5637 / #5653 backup parts (off), CI and test fixes: not user-facing.
