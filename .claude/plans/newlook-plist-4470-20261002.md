## Why this page
The umbrella's named order (project page, Agents, Tasks, an agent's page, Settings, phone) is built; Create was added.
Of the screens the look does not reach yet (Projects list, Documents, a task's page, project settings, New project),
the Projects list is the one a person passes through to reach the project page, the first slice.

## The call
The Projects list is drawn in the Agents board's grammar (count tiles, a dashed add tile, sort menu and view toggle,
then cards), so it takes the Agents page's approved new-look language, applied, not redesigned:
- the count tiles (Projects, Messages; both inert here, unlike the Agents Messages filter) lose their box;
  the Issue tile keeps its red outline;
- Add Project is the 40px round grey button with its words beside it (as New agent);
- the sort menu and the grid / roadmap toggle are grey pills; the current view stays gold (Josh, 2026-08-17);
- a plain project card loses border and shadow at rest, takes 24px corners, and KEEPS today's hover border and lift;
  a needs-you card keeps its red edge.

## Rejected
- Dropping the hover border too (what the Agents cards do): project cards today lift on hover, and a card with no
  edge needs a sign it opens (the Agents list rows' rule). Keeping it is the smaller change.
- Restyling the roadmap rows: they are already flat rows with no border, Josh's stripes (#4730) and a red needs-you
  ring. Touching a ruled view for no gain.
- Fixing the stretched "Done not set" pill in the roadmap here: it is on main with the look off, so it is its own
  card (#5070), not a look change.

## Weakest premise
That the Agents page's language transfers without a drawing of this page. Same as Tasks (no drawing either). Josh may
want something of his own here; it is CSS behind the switch, so it is one revert.
