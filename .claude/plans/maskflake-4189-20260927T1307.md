## Decided
- **Minimum, not median:** contention only ever adds CPU time to a run, so the fastest run is
  the one nearest the true cost.
- **Rejected:** a higher line with the median kept. That still carries the noise of the middle
  run, and review round 27's median did not stop this failure.
- **Weakest part:** 3x leaves about 1.1x of headroom over the worst healthy reading so far
  (2.01 under load) and about 1.8x under the mutant's lowest pair. A runner loaded worse than
  38 on 3 cores could still push healthy code near 3x. What would change my mind: a CI failure
  at the new line on unchanged code, which would argue for a work count instead of CPU time.
