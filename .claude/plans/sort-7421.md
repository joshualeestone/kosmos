# sort-7421: the iPhone Agents sort menu is the desktop's eight orders (kosmos#7421)

Josh, 2026-10-27 20:34 CDT: "The sort options for agent mobile should mirror the desktop app". Stacked on kcircle-7417
(TestFlight build 9 work). Plan and decision also on the card (comment 6459320139).

## Finished looks like
- The Agents sort menu offers Last talked to, By model, Name A to Z, Needs you first, Recently active, Newest first,
  By project, By role, in that order, default Last talked to, remembered per phone (the older "board" choice reads as
  Needs you first).
- Each sorts as the desktop's sortAgents: starred first (stars parameter, wired by #7034), the key, then name, then
  the computer's order; a missing value sorts last.
- A test reads AGENT_SORTS, the menu words and the default out of web/index.html, so the two cannot drift silently.

## Decisions
- Ported the comparators rather than having the board send an order: the desktop's model and role lines are worked
  out in the page, not the server. Weakest premise: By model and By role may group rare edge cases differently.
- By project reads /api/projects when that order is chosen (and on each visit), not on every poll.

- iOS 16 typecheck; all nine LogicTests scripts (main: the eight orders, stars, saved choice, model key, desktop
  lists; room: first project).
