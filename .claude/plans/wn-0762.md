The cut refuses unless web/whats-new.json is for the version cut (release.sh step 2b-ii), and main's is for 0.7.61.
This builds the list with `node tools/whats-new-pool.js build 0.7.62` (#5711: the top five since the last prod
release). Mac prod serves 0.7.61 (promoted 2026-10-20 11:16), so the build marks 0.7.61's five highlights shown and
records lastProd 0.7.61 in the pool (#5713); that pool change is committed with the build.

## The built list (top five)
Browse an agent's files (new); A team map for each project; Agents are told how to finish a task; See which agent
changed a file (mac only); A paused room says why. Mac 5, Windows 4.

## Decided
- New pool item "Browse an agent's files", rank 3, since 0.7.62: kosmos#6724 (merged as #6753 on 10-20) turns an
  agent's Files screen into a browser (folders and files, previews of images and text, a folder as one zip). PDFs are
  left out of the line on purpose: their preview is drawn by macOS only (engine/filepreview.js), and the item is not
  Mac-only, so naming them would be false on Windows (review 1). It
  is the release's most visible new feature and no pool item named it. The line states only what the PR's own
  description says the screen does; it says nothing about remote viewing, which only hides buttons.
- Its rank (3) puts it above "A team map for each project" (4) and pushes "A project shows each member's role" (12.5)
  out of the five; that item stays pending for a later list.
- No item for the night's security hardening (private-detail cards), as for 0.7.61.

- "A team map for each project" reworded (review 3): its line said only the Separate tabs view had the map, but since
  #6324 the consolidated layout shows it above the Agents list too (paintRailTeamMap, the same members-with-a-session
  rule in both), so the line now names both places and no longer says every project has one.

## Weakest premise
That each line is true on every platform it is shown on. The first version claimed PDF previews for Windows too,
which review 1 caught by reading the code per platform. The new line was then checked against its feature's code,
and so were the three carried items with no platform tag (review 2): the Team map and the paused room's note are in
web/index.html and server.js with no platform gate, and the finish-a-task hint is server.js's own reply to `kosmos
task message` (line 5457), which both platforms' boards run. The Mac-only item keeps its tag.

Second: that rank 3 is right for the Files browser. It was set here, against the existing ranks, by the release
owner alone.
