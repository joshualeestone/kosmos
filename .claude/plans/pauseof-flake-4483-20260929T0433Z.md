# #4483: engine/chat.dmnotice-4354's pauseOf test can fail by 1ms (Sonya Blade, 2026-09-29)

Assigned by Liu Kang (m2848); Kano hit it validating #4356.

## Finished means
The test cannot fail on timing: it builds the pause and states the expected start from ONE fixed instant, and a
run with a clock that advances 1ms on every read passes.

## Cause (measured)
`at(minAgo)` reads `Date.now()` on each call. The test built the pause with `Date.parse(at(3))` and expected
`pausedSince: at(3)`: two readings, so across a millisecond tick they differ.

## Fix
A fixed instant (`2026-09-28T12:00:00.000Z`) for both. Other `at()` uses in the file compare times minutes apart or
reuse one stored value (`notice.at`), so they are not affected; the sibling #4354/#4340/#4421 test files have no
two-reading comparison (grepped).

## Checks
- With a preload that makes Date.now advance 1ms per read: the old file fails that test (4 pass, 1 fail), the fixed
  file passes 5/5. Five plain runs: 5/5.
