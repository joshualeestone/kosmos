# Plan: archived label copy + View All font match (#3132)

## The ask
Josh, 6.68 feedback (consolidated + tab):
1. Change "Show archived projects (X)" to just "Archived (X)".
2. The "View All" under Tasks should be the SAME font size as the "Archived (X)"
   link on Projects.

## What finished looks like
- The archived-projects disclosure reads "Archived (X)" in both the tab and
  consolidated views, in both open and closed states.
- The Files/Tasks "View All" doors render at the same font size as the Archived
  link, in the view where they currently differ (consolidated).
- Tests + render-projects browser-check green.

## The change (web/index.html)
1. paintArchived (JS): the label was `(open?'Hide':'Show') + ' archived projects (N)'`.
   Now just `'Archived (' + N + ')'`. Open/closed state is carried by aria-expanded
   and the disclosure list, not by the label text. Same JS drives tab and
   consolidated, so one change covers both.
2. CSS: `.linkish` is .875rem, so the Archived toggle and .pj-viewall doors already
   match in the tab view. Consolidated overrides #pj-arch-toggle to .6875rem, so add
   `html[data-layout="consolidated"] body.consolidated .pj-viewall { font-size: .6875rem }`
   to match. Scoped to consolidated so the tab view keeps its already-equal .875rem.
   Both doors share .pj-viewall, so Files and Tasks stay consistent with each other.

## Verification
- docs/browser-checks/render-projects.js: the archived-toggle text assertion updated
  from 'Show archived projects (1)' to 'Archived (1)'.
- Full suite via tools/run-tests.sh.

## Decisions
- Label is a STATIC "Archived (X)" in both states (no Show/Hide variant), per Josh's
  "just Archived (X)". The disclosure state stays communicated by aria-expanded.
- Part 2 applied to both .pj-viewall doors (Files + Tasks), not only Tasks, to keep
  the two doors consistent (they are a matched pair from #2711 item 12) while
  satisfying the Tasks match Josh named.

## Weakest premises
- "Just Archived (X)" means a static label in both open and closed states. If Josh
  wants a "Hide" variant when open, that is a one-line change.
- The font mismatch Josh sees is in consolidated (Archived .6875 vs View All .875);
  the tab view is already equal. If he meant a different view/size, adjust the scope.
