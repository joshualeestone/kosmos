# winkill-8406: a kill guard in the Windows report hook (kosmos#8406)

## Decision
Windows needs its own guard. On a Kosmos Windows computer every agent, the board and the app are node.exe or
claude.exe processes of the person's login, so one `taskkill /F /IM node.exe` ends all of them at once: the same
irreversible-in-session harm #4671 guards on the Mac. No Windows incident is known. The guard is cheap and reversible
(KOSMOS_KILL_GUARD=off, as on the Mac), so the call is to build it rather than wait for the incident.

## Change
- engine/winkillguard.js: the twin of the bash hook's _kill_all_reason, for the Windows forms. It is a small
  quote-aware tokenizer, not a regex list (review round 1 measured a dozen misses and false refusals in the regex
  version). The text is split into commands on newlines, ; & && || and pipes, outside quotes. Only a command in
  command position counts: the first word, or the command inside cmd /c, bash -c or powershell -Command. So a word in
  a commit message, a grep pattern or a path is not a command. Switches may be /X, //X (Git Bash, which Claude Code's
  Bash tool uses on Windows) or -X, in any case. Refused:
  - taskkill /IM of a Kosmos image (node, claude, kosmos*, or a wildcard that matches one) unless /PID or a
    "PID eq n" filter narrows it;
  - taskkill /FI with no /PID and no other /IM (a filter alone ends every process it matches);
  - Stop-Process by any name in a -Name list (colon syntax and prefixes too);
  - Get-Process into Stop-Process unless named elsewhere or by -Id;
  - wmic process delete/terminate without a ProcessId;
  - logoff, shutdown with an end verb (not /a), Restart-Computer, Stop-Computer.
  Each reason carries its own consequence. Linear time on long lines (the rest of a pipeline is taken only for a
  process list; globbing is a two-pointer match).
- Review 7 changes: a heredoc body (quoted or capitals word) is data for its command, so the standard
  git commit -m "$(cat <<'EOF' ...)" and gh pr create --body forms are not refused, unless a shell reads the heredoc;
  the /FI value is parsed without backtracking (a value of 200k spaces had been quadratic); MODULES and a WINDOWTITLE
  of N/A or * are broad filters; logoff followed by a bracket is code; (Get-Process x) | Stop-Process and cmd /c"..."
  are read; ${#a} is not a comment.
- Known: this branch's own test file is refused if an agent WRITES it on Windows (it holds the refused commands as
  strings, and a shell reader cannot pair a JS file's quotes). Only Windows agents run this hook; the operator's
  KOSMOS_KILL_GUARD=off is the way to edit it there.
- Review 6 changes: a redirect glued to an image name (node.exe>nul) no longer hides it.
- Review 5 changes: brackets are matched in one linear pass with the tokenizer's quote rules, so an unmatched
  ( or { (a smiley, a regex literal) stays a character and cannot hide the rest; $( ) inside double quotes and <( )
  are read; | % { Stop-Process $_ }, % Kill and (Get-Process x).Kill() are refused; bash if/while, cmd if exist /
  errorlevel and @cmd lines reach their command; # and <# #> comments are skipped; taskkill /FI IMAGENAME eq or
  WINDOWTITLE eq another program, and wmic name= another program, pass with correct messages; logoff /?,
  Restart-Computer -WhatIf and -ComputerName another computer pass.
- Review 4 changes: $( ... ) is read wherever it is, batch for ... do runs its command, tskill by name,
  Stop-Process (Get-Process ...) and | % { $_.Kill() } are refused, and a long chain of ps stages is linear.
- Review 3 changes: wrapper lookup is a Map (a command word of constructor or __proto__ had thrown, and the hook
  skipped its report and keep-copy); main() catches any guard error and goes on; a block is read as commands only at
  the start of a command or after a control keyword, never as a call's arguments or an object literal, so source code
  defining or calling logoff/shutdown is not refused (a sweep of 1601 repo files refuses none); a Kosmos /IM beside a
  /PID is refused (taskkill's /PID and /IM add processes; only /FI narrows); powershell's bare words, iex, start
  "title", sudo/exec, @( ) name lists, -WhatIf, a negated Where-Object and shutdown /m localhost are handled.
- engine/kosmos-report-hook.js main(): the check runs first on every event. A refused PreToolUse returns 2 with the
  reason on stderr, before anything is sent to the board.
- install/kosmos-report-hook.sh: its "Not guarded at all: Windows agents" note now points here.

## Rejected
- Porting the Mac's -1 shapes: Windows has no kill(-1); Git Bash's kill is MSYS-only and not how Windows sessions end.
- Refusing every taskkill /IM or Stop-Process -Name: an agent ending its own notepad or test server by name is
  ordinary; only Kosmos's own names, wildcards that match them, filter-only and session forms end everything.
- The first build's regex list: it missed Git Bash's // switches (the shape most likely typed), other /FI filters,
  multi-name Stop-Process and flag-only Get-Process, refused bare mentions of logoff and shutdown, and went quadratic
  on long lines.
- Waiting for a Windows incident: the Mac's came without warning and cost a whole session.

## Weakest premise
That the listed shapes are the ones an agent would type. It is a text seatbelt: computed names, scripts that build
the command, a command inside another program's quoted argument, and unlisted shapes pass. A mention inside an
argument (a commit message, a grep) is NOT refused, because only command position counts. What is refused although
harmless is a refused command as a line of text a tool writes to a non-.md file or feeds through an unquoted heredoc
(cat <<EOF / logoff / EOF), since that text can be run. The widest hole it leaves is a Where-Object that tests
something other than a name (Get-Process | Where-Object { $_.CPU -gt 100 } | Stop-Process passes): only a name can be
judged from text, and refusing every filtered Stop-Process would refuse ordinary narrow ones.

## Test
engine/kosmos-report-hook.win32-killguard-8406.test.js ("win32" puts it on the Windows CI job; pure, so any host):
107 refused forms (Git Bash // switches, filters, name lists, wrappers, blocks, substitutions), 65 allowed forms (the card's control
taskkill /PID 4242, /PID or PID-filter narrowing, other names, mentions in commits, greps and paths), long lines under
1.5 s, the hook returning 2 with the reason and sending nothing while the /PID control does send, KOSMOS_KILL_GUARD=off,
and which fields are read.
