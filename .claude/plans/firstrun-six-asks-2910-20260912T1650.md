# firstrun-six-asks-2910 -- six folder-access asks (Terminal + Kosmos) on the install Access screen

Card: kosmos#2910 (label: josh-review). Josh's 6.59 QA, verbatim:
"On the first screen of install, where Kosmos needs your permission and we're asking to
grant access to the three different folders, I also want to add the three different folder
asks for Terminal. Three for Kosmos and three for Terminal, all six in a row. Right now we
show that it's Terminal asking for access on that screen but then when it pops up, it's
actually Kosmos asking for it. We really need both so let's ask for both."

## What finished looks like
The install Access pane (S2, `#fr-pane-2` in web/index.html) shows SIX macOS-style permission
previews grouped as two labeled sets: Terminal (Documents / Downloads / Desktop) and Kosmos
(Documents / Downloads / Desktop). Each preview names the correct app (not the single
mislabeled "Terminal" box). The one-box browser-check is rewritten to assert the six-ask
layout and the correct labels, and it passes headless via pw-runtime. Node suite + browser-check
gate green. challenge-loop converged. PR (no human reviewer -- Kosmos gate is the challenge-loop).

## Design decision (mine, per Josh's explicit 6.59 words; documented because it reverses a prior call)
- This REVERSES the 0.6.39 #8 simplification (Mona's spec: replace the three-card fan with ONE
  compact prompt). Josh's 6.59 instruction is explicit and newer and on the same screen: he now
  wants six asks. Newer explicit same-person ruling on the same surface wins.
- The mislabel: the current single mock says `"Terminal" would like to access files in your
  folders.` Josh says the real popup is Kosmos. Both apps DO trigger TCC prompts (tmux runs under
  Terminal; the Kosmos app accesses files too), which is why he says "we really need both". So the
  fix is not to relabel one box Kosmos, it is to show BOTH apps' asks, each labeled correctly.
- Layout: two labeled groups, three compact previews each, six total ("in a row" -> a clean
  wrap-friendly grid, not a rigid single line that breaks at phone width). Each preview keeps the
  existing compact `.s2-dlg` styling and the gold-ringed Allow, so it still reads as the real macOS
  prompt. The single real gate row (`.s2-gate-row`, Renet's poll) is unchanged -- it is the actual
  grant state, separate from the previews; #2910 is about the previews/asks, not the grant wiring.

## Weakest premise (named)
"Six in a row" is interpreted as two labeled groups of three in a wrap-friendly grid; Josh may have
pictured a literal single row of six. Reversible in a commit, and josh-review means he eyeballs it
in-app; if he wants a strict single row, it is a CSS one-liner. The app-both-ask claim (both Terminal
and Kosmos trigger TCC prompts) is grounded in the existing code comments (line ~11356 "Kosmos wants
to access files") + the tmux-under-Terminal model; if only one app actually prompts on a given
machine, showing both still correctly sets expectations rather than misleading.
